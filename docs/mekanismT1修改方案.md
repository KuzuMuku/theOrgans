# Mekanism T1 基础工业义体与能源管线实现稿

## 0. 总纲

Mekanism T1 的核心不是“护盾机甲”，也不是“能量条换爆发”。T1 的核心是**能源流转**：从热能、电力、气体、加工链里拿到能量，让能量在管线、电容、热泵、化学回流和矿物处理之间流动，最后回到工业回路里继续使用。

本稿继续保留 `kubejs:mek_energy / kubejs:mek_energy_capacity` 作为唯一资源条，但它的定位不是战斗爆发池，而是“工业能量库存”。T1 的强度来自：

- 输入是否稳定：热泵、击杀、挖掘、加工。
- 转换是否高效：气体回流、矿物加工、副产物返还。
- 输出是否有节奏：热刃、磁轨、裂解矿囊、机动切入。
- 过载是否有代价：过热、损耗、冷却。

T1 不做的方向：

- 不主打护盾、量子、纳米复制、相位切断。
- 不把 Mekanism 变成 Iron's Spells 法术倍率来源。
- 不做复杂机器编排，不做多套平行能量条。

---

## 一、来源与流派

```text
来源：Mekanism.T1（基础工业义体）
加成主题：高科技 / 蒸汽朋克
主要流派：能源流转 / 热能穿甲近战 / 工业增产
核心资源：kubejs:mek_energy / kubejs:mek_energy_capacity
```

玩家玩法判断：

- “这条能量是从热泵来的，还是从加工回流来的？”
- “我要把能量导给热刃、磁轨、裂解矿囊还是机动腿栓？”
- “我是否搭好了回路，让能量不会只进不出？”

---

## 二、核心资源与能源路径

唯一资源条：

```text
kubejs:mek_energy：当前工业能量
kubejs:mek_energy_capacity：工业能量上限
```

短时 runtime 状态：

- `mek_t1_heat_cycle`：热区/热放窗口。
- `mek_t1_flow_cycle`：能源流转窗口。
- `mek_t1_rhythm_cycle`：连续动作节拍。
- `mek_t1_refinery_cycle`：气体/矿物加工回收窗口。
- `mek_t1_discharge_window`：命中或受击后的效率窗口。
- `mek_t1_overload_window`：工业回路过载窗口。

能源路径建议：

```text
热泵产能 / 击杀 / 挖掘 / 加工返能
  -> kubejs:mek_energy
  -> 热刃、磁轨、裂解、机动、回路核
  -> 副产物回流、热损耗、冷却
```

T1 的核心目标是让这条路径转起来，而不是单纯把能量攒高然后一次性清空。

## 三、非器官装配线

除义体器官外，T1 应加入纯工业“电线、管道、接口”作为本体。它们不占生物器官意象，可以出现在手术装配、机械插槽、材料链或启动判定中。

| 装配件 | 定位 | 设计作用 |
|---|---|---|
| `基础电力导线` | 线路 | 把能量从能核导向主动部件，降低单一节点压力 |
| `热交换管` | 管道 | 传递热能，增强热泵与热刃的持续输出 |
| `化学气体管道` | 管道 | 让气体回流和矿物处理回到同一条工业回路 |
| `电容母线` | 接口 | 连续动作期间技能能量消耗 -1 点 |
| `矿物输送轨` | 传送 | 把裂解矿囊与加工返利串成资源线 |

这些组件不需要都写成“某生物的器官”。它们本身就是 Mekanism T1 的身份来源。

## 五、核心组件：能源回路核

T1 的新核心不再采用“消耗一半能量 -> 全面增幅”的模板。它应该让玩家真正看到“能量从管线里流过去再回来”。

`energy_loop_core`

- 来源：基础电力、热能、气体管道和钢铁机壳毕业件。
- 主要流派：全部 T1 流派共享的能源流转落点。
- 主要效果：主动开启 `mek_t1_flow_cycle`，持续 8 秒。期间耗能主动件的消耗降低 25%，击杀、挖掘、加工返能增加 50%，热泵与气体回流效率提升；释放后进入短暂热损耗窗口，但不要求清空当前能量。
- 触发条件：当前能量不低于 20，且 T1 体系在线。
- 限制 / 代价：开启后能量不再自动上涨，只有行为和加工才能回流；热损耗窗口内空耗变高，不能无限循环。
- 强联动：工业能核、热泵循环肺、气体回流囊、精馏滤胆、热刃臂、裂解矿囊。

这个核心做的是“强化能量流转效率”，不是“清空能量换一次爆发”。

---

## 六、推荐联动范式

1. 热力输入链

```text
工业能核 -> 热泵循环肺 -> 导热骨板 -> 热刃臂
```

目标：热能和热区活动转为持续近战输出。

2. 气体/副产回流链

```text
工业能核 -> 气体回流囊 -> 精馏滤胆 -> 精炼回收腺 -> 能源回路核
```

目标：击杀、挖掘和加工都回到工业回路。

3. 主动工业打击链

```text
工业能核 -> 电容节律腺 -> 校准透镜眼 -> 磁轨拳峰 -> 磁轨腿栓
```

目标：命中/受击后触发短窗口，把能量转成穿甲重击和切入。

4. 矿物处理链

```text
工业能核 -> 裂解矿囊 -> 精馏滤胆 -> 精炼回收腺 -> 磁轨腿栓
```

目标：长期挖矿加工，不需要依赖战斗击杀。

## 七、实现要点

- 继续使用 `mekanismT1_set_major` 与 `mekanismT1_resource_online`。
- 删除 T1 内 T2 身份词：护盾、量子、纳米、相位切断、锁定弹道终局。
- 非器官装配件可以先作为配方材料、启动条件、固定增益或独立机械插槽落地。
- 优先实现事件：`move`、`deal_damage`、`attacked`、`mine`、`kill`、`skillCast`、熔炼/粉碎/加工回调。
- 能源回路核不应简单等于“消耗一半能量 -> 大窗口”。

---

## 八、与 Mekanism T2 的区分

| 维度 | T1 | T2 |
|---|---|---|
| 核心感觉 | 能源流转 | 科幻机甲 |
| 资源 | 工业能量 | 量子护盾 |
| 主要方向 | 热/气/矿/加工 | 锁定/相位/纳米/护盾 |
| 核心主动 | 能源回路，强化流转返还 | 机甲协议，强化战术执行 |

T1 的玩家应该感觉自己经营一套能量管道，而不是开一台量子机甲。

- 文档中同时包含器官与电线/管道/母线等非器官组件。

- 核心不再用“清空一半能量 -> 全面大爆发”的写法。
