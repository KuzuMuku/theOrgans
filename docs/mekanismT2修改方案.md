# Mekanism T2 量子同步机甲实现稿

## 0. 总纲

Mekanism T2 的核心是**科幻机甲 + Mekanism 后期辐射/裂变/等离子技术**。它不是 T1 的“身体内能源管道”，也不是简单的“激光远程套”。T2 的玩家应该感觉自己穿着一套连接基地能源的高阶量子机甲：

- 护盾不是身体自己发电恢复，而是由基地能源通过跨维度同步方块接入身体。
- 玩家可以在基地放置量子同步方块，把基地的电力、裂变/辐射/等离子产线接到身上。
- 玩家身体只保留护盾、锁定、纳米、辐射层这些执行层；能源来源在基地。
- 所有加护盾或依赖护盾的操作，底层都消耗基地同步来的 `kubejs:mek_energy`。

T2 高层玩法因此分成两段：

1. 基地侧的能源准备：核裂变、辐射处理、等离子仓储、跨维度同步方块。
2. 身体侧的机甲执行：护盾、锁定、相位切、光矛、辐射偏折、等离子爆发、纳米复制。

## 一、来源与流派

```text
来源：Mekanism.T2（未来义体 / 量子护盾 / 辐射 / 裂变 / 等离子）
加成主题：高科技
主要流派：辐射近战压制 / 等离子远程爆发 / 终局资源复制
核心资源：kubejs:mekanismT2_barrier / 护盾上限
底层能量：kubejs:mek_energy（来自基地同步）
```

T2 不再体内发电，但需要管理两个层面的准备：

- 玩家在基地准备高能电源、辐射/裂变源、等离子燃料，并通过 `量子同步方块` 连到身体。
- 玩家在外面战斗时，护盾回充、技能释放、纳米修复都以 `mek_energy` 作为实际消耗。

## 二、核心资源与基地能源链接

唯一显示资源条：

```text
kubejs:mekanismT2_barrier：当前量子护盾
kubejs:mekanismT2_barrier_capacity：护盾上限
```

底层随能量：

```text
kubejs:mek_energy：量子同步方块从基地接入身体的能量
```

### 量子同步方块

新增基地方块：

```text
kubejs:quantum_sync_cube
```

它不装在身体上，而是放在基地里。

- 方块连接基地的电力矩阵、裂变反应堆、辐射处理链或等离子仓储。
- 当玩家处于链接范围内，或穿着/装配 T2 核心组件时，方块会把基地能量同步到 `kubejs:mek_energy`。
- 没有这个方块，或基地能量不够时，T2 的护盾回充、主动技能、纳米修复、量子协议都无法完整工作。

### 能量消耗规则

以下行为都会底层消耗 `kubejs:mek_energy`，而不是免费生效：

- 护盾恢复。
- 护盾破裂后重新建立。
- 量子过载窗口。
- 纳米修复。
- 纳米复制。
- 量子机甲协议。
- 裂变等离子炉室的高能阶段。

身体上不再出现热泵肺、气体回流囊、矿物裂解矿囊这类“体内发电/回收”装置。

## 四、非器官装配线

T2 需要大量“机甲部件”和“基地设施”，不局限于生物器官。

| 装配件 | 定位 | 设计作用 |
|---|---|---|
| `量子同步方块` | 基地方块 | 把基地能量/辐射/等离子接入身体 |
| `量子导线` | 线路 | 在同步方块和身体组件之间传输能量 |
| `相位线圈` | 执行件 | 相位斩和光矛进入过载窗口所需时间 -1 秒 |
| `纳米修复线路` | 维护线 | 护盾不低于 50% 时，技能冷却缩减 +1；护盾低于 50% 时每 3 秒恢复 2 点护盾 |
| `锁定传感器阵列` | 感知件 | 建立锁定窗口，提高远程命中和穿透 |
| `裂变燃料极` | 燃料件 | 驱动裂变等离子炉室的高能阶段 |
| `辐射过滤网` | 过滤件 | 把环境辐射/击杀辐射转换为可控层数 |

这些部件是未来义体和基地基础设施，而不是“某生物的器官拼到身上”。

## 六、新增核心组件

### 裂变等离子炉室

`fission_plasma_chamber`

- 来源：量子封装膜、HDPE、原子合金、精英电路、裂变燃料极、量子同步方块接口。
- 定位：T2 的辐射/裂变/等离子终点之一，不是“再开一层盾”。
- 主要效果：主动进入 `mek_t2_plasma_window`，持续 6 秒。期间光矛与相位切伤害 +10%，穿透 +1 目标；近战命中释放 1 点辐射热点。
- 触发条件：当前护盾不低于 36，`mek_energy` 不低于 25，且基地有裂变燃料。
- 限制 / 代价：消耗护盾和能量，结束后进入辐射冷却；如果不是量子同步方块在线，无法开启。

### 量子机甲协议

`quantum_mecha_protocol`

- 来源：全身 T2 组件的核心执行协议。
- 定位：把锁定、护盾、辐射、等离子、纳米串成一个战术窗口。
- 主要效果：主动进入 `mek_t2_overload_window`，持续 8 秒。期间锁定命中率 +15%，相位斩伤害 +10%，光矛穿透 +1 目标，辐射层转化速度 +20%。
- 触发条件：当前护盾不低于 18，`mek_energy` 不低于 20，且至少存在锁定、辐射或纳米维护窗口。
- 限制 / 代价：启动保留大部分护盾，但会消耗 `mek_energy`；协议结束后 3 秒内不能再次进入量子过载。

## 七、辐射 / 裂变 / 等离子构图

T2 不应只描述为“能量护盾 + 激光”。

### 辐射

- `辐射扩散核` 从辐射环境、污染杀敌和受击中积累 `mek_t2_radiation_layer`。
- 辐射层有上限；除 `辐射偏折装甲` 外，过量辐射会转化为负面，不能无限储存。
- 辐射层是“高价值但危险”的备用资源，可被量子协议和裂变炉室消费。

### 裂变

- 基地端通过裂变燃料、辐射处理链和量子同步方块提供能量。
- 身体端不建裂变反应堆，只保留 `裂变等离子炉室` 作为能量/辐射/等离子转换节点。
- 玩家需要回基地准备裂变燃料，不能靠杀怪无限白嫖。

### 等离子

- `等离子态线路` 负责高能阶段稳定。
- `光矛抛射腱` 和 `相位切断臂` 在 `mek_t2_plasma_window` 内获得等离子属性。
- 等离子是一种高阶战斗状态，不该成为 T1 的“热/气/矿加工”复读。

## 八、推荐联动范式

1. 基地供能链

```text
基地电力/裂变/辐射源 -> 量子同步方块 -> 量子护盾核 -> 全身 T2 组件
```

目标：让玩家先理解“机甲在外面输出，基地在身后供能”。

2. 护盾机甲链

```text
量子护盾核 -> 等离子动力管 -> 纳米充能网络 -> 量子步进模块
```

目标：用基地能量维持护盾和机动，保证机甲不因为一次受击崩盘。

3. 辐射近战链

```text
辐射扩散核 -> 辐射偏折装甲 -> 量子过载回路 -> 相位切断臂 -> 量子机甲协议
```

目标：把辐射层变成近战压制，开协议后整体执行。

4. 等离子远程链

```text
锁定传感器阵列 -> 演算阵列 -> 裂变等离子炉室 -> 等离子态线路 -> 光矛抛射腱
```

目标：先锁定、再演算、再开等离子窗口，最后光矛爆发。

5. 纳米收割链

```text
量子护盾核 -> 纳米修复线路 -> 零损采样探头 -> 纳米复制单元 -> 演算阵列
```

目标：把护盾和基地能量转成低频稀有材料收益。

## 九、实现要点

- T2 保留 `kubejs:mekanismT2_barrier` 作为最终显示资源条。
- T2 所有护盾操作底层消耗 `kubejs:mek_energy`，身体不再安装热泵、气体回流或加工回收类组件。
- 新增 `kubejs:quantum_sync_cube` 作为基地方块，负责跨维度接入基地能源。
- 如果实现上更希望用 Mekanism 原生跨维度同步接口，可以用现有量子传送接口替代自定义方块，但文档语义统一写“基地同步到身体”。
- 辐射层、锁定、过载、等离子窗口都进入短时状态，不进入资源条 UI。
- 优先实现事件：`move`、`sprint`、`deal_damage`、`projectile_hit`、`attacked`、护盾损失、`skillCast`、基地供能检测。

## 十、与 Mekanism T1 的区分

| 维度 | T1 | T2 |
|---|---|---|
| 核心感觉 | 能源流转 / 基础工业管线 | 科幻机甲 / 辐射裂变等离子 |
| 能量来源 | 身体管线：热泵、气体、加工 | 基地供能：量子同步方块 |
| 护盾 | 无主护盾 | 护盾是核心资源 |
| 战斗终点 | 热刃、磁轨、裂解矿囊 | 相位斩、光矛、辐射层、等离子窗口 |
| 核心主动 | 能源回路，强化流转返还 | 量子机甲协议，串起锁定/护盾/辐射/等离子 |

T2 不是 T1 的数值加强版，而是把能源从身体端转移到基地端的新玩法结构。

## 十一、验收标准

- T2 扩展到 20 个可落地组件。
- 所有加护盾、恢复护盾、使用护盾技能的行为都消耗 `kubejs:mek_energy`。
- 文档明确包含 `量子同步方块`，玩家不需要在身体里自行发电。
- 辐射、裂变、等离子不是文案点缀，而是有实际词条：辐射层、裂变燃料、等离子窗口。
- 既有 T1 热泵、气体回流、加工回收不会出现在 T2 主词条。
