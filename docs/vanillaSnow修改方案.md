# 原版雪原实现稿

## 本轮调整结论

雪原不再保留“寒势储能 -> 半量释放 -> 再储能”的统一循环。雪原更适合被写成低温结晶与霜脉网络：寒势是持续低温饱和状态，由凝华导管和霜脉在器官之间流动，核心开启极寒领域，而不是清仓放一个 Ice Block。

- 保留 `vanillaSnow_resonance`，但定位改为“寒势结晶”，进入不同低温区间会改变生存、冰法和反打节奏。
- 新增 `凝华导管`、`霜脉束`、`冰芯节律器` 三类非器官辅助件，作为雪原体系的“血管”。
- `霜寒主核` 改为持续极寒窗口，按秒耗寒势，不直接释放 `irons_spellbooks:ice_block`。
- 雪域标记保留为锁定状态，但不承担资源功能。

本文对应 [design-vanilla-snow.txt](/home/kuzuanpa/projects/1.20.1/theOrgans/organs/vanillaSnow/design-vanilla-snow.txt:1) 的施工图版本。上游概念稿负责说明“雪原体系是什么”，本文负责回答每个器官最后装什么、触发什么事件、消耗和产出什么资源。

本文沿用 vanillaShulk 实现稿的取舍原则：

- 保留来源与主场条件，不为了扩题材破坏“原版群系.雪原”的身份。
- 保留现有 10 个器官的基础面板，只收敛功能类特效，删掉多余堆叠。
- 把多段候选效果收敛成“寒势结晶 + 雪域标记 + 霜脉辅助件”。
- 用 Aquamirae 冰迷宫内容的真实 Boss、结构、实体、战利品补齐资源与毕业来源，并用持续极寒领域替代半量清仓主动。
- 保留现有 10 个器官，新增 1 个 Aquamirae 核心器官，共 11 个。

文中的 Aquamirae 内容按本整合包实际使用的 `aquamirae-forge-1.20.1-6.4.0.jar` 核对，mod id 为 `aquamirae`。

## 一、来源与主场

来源定位是：

```text
原版群系.雪原 + Aquamirae.寒海冰迷宫
```

Aquamirae 不单独成为新来源。它在本稿中作为雪原来源的“极寒深海 / 冰迷宫 / 海船墓地”延展层，负责提供结构入口、高阶猎杀目标和核心主动来源。这样既能保留“原版群系.雪原”稳定生态的身份，也不会让雪原变成“海洋模组合集”。

### 主场条件

保留现有 `vanillaSnow_runtime.js` 的判定不变：

- runtime 的 `HOME.dimensions` 继续保留 `minecraft:overworld`，实际生效主轴只使用维度、群系和结构判定。
- 群系关键字包含 `snow`、`frozen`、`ice_spikes`、`grove`。
- 附近存在 `minecraft:igloo`，结构半径沿用 8 chunk。

实现时只对结构表做一处扩展：

1. `HOME.structures` 加入 `aquamirae:ship`、`aquamirae:outpost`、`aquamirae:shelter`，继续保留 `minecraft:igloo`。
2. 不新增“endless_ice_maze 世界预设”作为独立维度来源，只吸收主世界冻洋中的 Aquamirae 世界生成内容。
3. 不新增 Aquamirae 专属 biome 条件，因为 `#aquamirae:ice_maze` 在本包中是 `minecraft:frozen_ocean` 与 `minecraft:deep_frozen_ocean`，现有 `frozen` 关键字已经覆盖。

基础能力必须离开主场也可用。雪原/降雪/冰面只作为额外强化层和资源积累层，不能出现“离开雪原器官直接失效”的问题。

## 二、核心资源与状态

### 1. 寒势

保留现有 `kubejs:vanillaSnow_resonance`，展示名继续用“寒势”（现有 runtime 显示名“霜压”）。它不再只是低温储能，而是身体里的低温结晶饱和度。

- 额度：默认 50 点，由霜封心室提供；白桦髓肝 +8，霜寒主核 +25。
- 结晶端：冰法命中、近战命中、受击、寒地采集、极地/冰迷宫生物猎杀。
- 消融端：离开寒冷环境、接触热源、凝华导管主动散热、核心开启极寒领域。
- 结晶区间：
  - 低结晶：基础能力可用，适合转场和续蓝。
  - 中结晶：冰法伤害 +1，雪域标记持续时间 +1 秒。
  - 高结晶：击退抗性 +2、受击反打伤害 +2，但每 3 秒损失 1 点寒势。
- 出口不再是“半量清仓 Ice Block”，而是 `霜寒主核` 开启一个持续耗势的极寒领域。

### 2. 雪域标记

保留现有 `mark:kubejs:vanillaSnow_mark`，展示名“雪域标记”。它只代表目标已被近战冰碴锁定，不承担经济资源功能。

- 上标记：冰碴臂束近战命中。
- 吃标记：雪盲虹膜远程命中带标记目标时施加发光与强减速，不再强制消耗寒势。

### 3. 负面抑制与综合增强

- 负面抑制：霜封心室在主场缓慢抑制冻结积累，但不复制 Aquamirae 三栓潜水服的防冻能力；Aquamirae 的原生装备效果继续由原装备负责。
- 综合增强：白桦髓肝给法力底盘，冰晶肺叶给冰法强度与施法节奏，寒光冠脑给冷却缩减与冰抗，霜封心室给生命、护甲和高寒势自愈，冻土胸甲膜/霜蹄腿腱负责站场和机动。

### 4. 非器官辅助件（血管 / 霜脉）

雪原需要把寒势从生产件导到反打件和核心，而不是每个器官直接读同一个数值。以下辅助件不套 `<原版雪原> + <器官名>`。

| 辅助件 | 定位 | 设计作用 |
|---|---|---|
| `凝华导管` `kubejs:deposition_conduit` | 冷量管路 | 高结晶时每 5 秒消耗 2 点寒势，获得 `minecraft:resistance` 1 级 3 秒，并使冻结时长 -1 秒 |
| `霜脉束` `kubejs:frostvein_bundle` | 传导束 | 连接冰碴臂束、雪盲虹膜与霜蹄腿腱；4 件雪原器官在线时雪域标记持续时间 +1 秒，霜蹄腿腱移动速度 +1 |
| `冰芯节律器` `kubejs:icecore_rhythm` | 节律件 | 极寒领域开启期间每 3 秒返还 1 点寒势 |

这三件负责把雪原从“储电放电”改成“低温网络维持”，像血管、神经和心脏节律器一样存在。

## 五、器官详细词条

### 1. 霜封心室 `kubejs:frostseal_ventricle`

- 来源：原版雪原 + Aquamirae 寒海。
- 主要流派：寒地法斗 / 防反站场。
- 输出 / 成长方向：生命、护甲、资源容量、低温自愈。
- 主要效果：寒势 ≥ 25 时，每 30 秒消耗 2 点寒势回复 1 点生命；主场时每 10 秒降低一次冻结积累。
- 触发条件：静态面板 + 寒势阈值 + `vanillaSnow_home`。
- 强联动：所有寒势生产器官、霜寒主核。
- 限制 / 代价：回血不是无条件回血，必须积累到阈值并消耗寒势；冻结抑制不是免疫，Aquamirae 三栓潜水服的原生防冻不并入器官。
- Synergia 元素点：冰（3）。

### 2. 冻土胸甲膜 `kubejs:frozensoil_chest_membrane`

- 来源：原版雪原 + Aquamirae 寒海。
- 主要流派：霜壳站场。
- 输出 / 成长方向：护甲、护甲韧性、击退抗性。
- 主要效果：处于雪原/冻洋群系、`minecraft:igloo` 或 Aquamirae 结构时，获得击退抗性 +2。
- 触发条件：`vanillaSnow_home`。
- 强联动：霜封心室、冻裂髓鞘。
- 弱联动：Aquamirae 船/哨站/庇护所结构主场。
- 限制 / 代价：只做站场，不额外给生命；离开雪冰环境只保留基础护甲/韧性。
- Synergia 元素点：冰（2）。

### 3. 白桦髓肝 `kubejs:birchmarrow_liver`

- 来源：原版雪原 + Aquamirae 寒海。
- 主要流派：冰法续航。
- 输出 / 成长方向：最大法力、法力恢复、寒势转法力。
- 主要效果：寒势 ≥ 10 时，每 2 秒消耗 1 点寒势恢复 2 点法力。
- 触发条件：寒势阈值 + tick 节奏。
- 强联动：冰晶肺叶、寒光冠脑、霜寒主核。
- 限制 / 代价：不再同时做“施法回蓝、主场加蓝、击杀回蓝”；一套雪原续航只保留“寒势转法力”一个落点。
- Synergia 元素点：冰（4）。

### 4. 冰晶肺叶 `kubejs:icecrystal_lung`

- 来源：原版雪原 + Aquamirae 寒海。
- 主要流派：冰法蓄势。
- 输出 / 成长方向：冰法强度、施法时间缩减、寒势生产。
- 主要效果：`organironspell:spell_hit`，school 为 `irons_spellbooks:ice` 时 +2 寒势。
- 触发条件：冰系法术命中。
- 强联动：白桦髓肝、寒光冠脑、霜寒主核。
- 限制 / 代价：不再额外打范围伤害、不再无条件给所有冰法命中目标减速；冰法命中只负责“生产寒势”。
- Synergia 元素点：冰（6）。

### 5. 寒光冠脑 `kubejs:frostlight_crown`

- 来源：原版雪原 + Aquamirae 寒海。
- 主要流派：冰法节律。
- 输出 / 成长方向：冷却缩减、冰魔法抗性、施法移速。
- 主要效果：处于雪原/冻洋群系或 `minecraft:igloo` 结构时施法移速 +1；冷却缩减与冰魔法抗性由面板提供。
- 触发条件：`vanillaSnow_home`。
- 强联动：冰晶肺叶、雪盲虹膜。
- 限制 / 代价：不再承担“冰法冷却后回蓝”，把法术节律收敛为一道白热施法线。
- Synergia 元素点：冰（4）。

### 6. 雪藏脾囊 `kubejs:snowhide_spleen`

- 来源：原版雪原 + Aquamirae 寒海。
- 主要流派：寒地打捞 / 冰迷宫猎杀。
- 输出 / 成长方向：资源成长。
- 主要效果：挖掘雪块、雪层、冰、浮冰、蓝冰，或击杀原版极地生物/Aquamirae 冰迷宫生物时，+2 寒势并 roll 一次寒地材料。
- 可用奖励方向：雪球、浮冰、兔皮，以及 Aquamirae 真实常见材料 `aquamirae:fin`、`aquamirae:sharp_bones`、`aquamirae:spinefish`、`aquamirae:esca`、`aquamirae:anglers_fang`、`aquamirae:jellyfish_jelly`、`aquamirae:ship_graveyard_echo`。
- 触发条件：`mine` + 雪/冰方块过滤；`kill` + 原版极地/Aquamirae 实体过滤。
- 强联动：霜蹄腿腱、冻土胸甲膜。
- 限制 / 代价：不复制 Boss 独有掉落，例如冰冻钥匙、风暴符文、深渊紫水晶；那些仍由 Aquamirae 原生战利品负责。
- Synergia 元素点：冰（2）。

### 7. 冰碴臂束 `kubejs:icechip_arm`

- 来源：原版雪原 + Aquamirae 寒海。
- 主要流派：近战上标 / 雪盲压制先手。
- 输出 / 成长方向：攻击伤害、标记、寒势叠层。
- 主要效果：近战命中时 +1 寒势，并给目标上 `mark:kubejs:vanillaSnow_mark`。
- 触发条件：`deal_damage`。
- 强联动：雪盲虹膜。
- 弱联动：霜蹄腿腱。
- 限制 / 代价：只负责上标和 +1 寒势，不额外做无条件减速、发光或反伤。
- Synergia 元素点：冰（3）。

### 8. 雪盲虹膜 `kubejs:snowblind_iris`

- 来源：原版雪原 + Aquamirae 寒海。
- 主要流派：远程/冰法压制。
- 输出 / 成长方向：远程压制、标记消费、寒势消耗。
- 主要效果：远程投射物命中带雪域标记的目标时，施加 4 秒发光与 3 秒强减速；若 `霜脉束` 在线，则强减速延长 1 秒。
- 触发条件：`projectile_hit` + 目标带 `vanillaSnow_mark`。
- 强联动：冰碴臂束。
- 弱联动：寒光冠脑、霜蹄腿腱。
- 限制 / 代价：没有标记时不免费给所有远程命中上 debuff；不消耗寒势，避免所有控制都变成同一套资源压力。
- Synergia 元素点：冰（3）。

### 9. 霜蹄腿腱 `kubejs:frosthoof_tendon`

- 来源：原版雪原 + Aquamirae 寒海。
- 主要流派：寒地追击。
- 输出 / 成长方向：移动速度、击退抗性。
- 主要效果：处于雪原/冻洋群系或 `minecraft:igloo` / Aquamirae 结构时，移动速度 +1、击退抗性 +1。
- 触发条件：`vanillaSnow_home`。
- 强联动：冰碴臂束、雪盲虹膜、雪藏脾囊。
- 限制 / 代价：只做机动，不产寒势，不额外给攻击/施法。
- Synergia 元素点：冰（1）。

### 10. 冻裂髓鞘 `kubejs:freezebreak_sheath`

- 来源：原版雪原 + Aquamirae 寒海。
- 主要流派：冰裂反打。
- 输出 / 成长方向：受击蓄力、寒势转化、短时护体。
- 主要效果：受击或冰系法术命中时叠寒势；寒势 ≥ 20 时，受击消耗 2 点寒势获得短时 `minecraft:resistance`。
- 触发条件：`attacked` / `spell_hit` + 寒势阈值。
- 强联动：霜封心室、冻土胸甲膜。
- 弱联动：霜寒主核。
- 限制 / 代价：不把“治疗 + 抗性 + 反伤 + 追伤”都堆在一个器官里；本器官只做受击蓄势和护体。
- Synergia 元素点：冰（2）。

### 11. 霜寒主核 `kubejs:frozen_maze_core`

- 来源：解剖 `aquamirae:maze_mother` 获得，承接原取舍稿中“霜寒主核”的定位。
- 面板：`vanillaSnow_resonance_capacity +25`、冰亲和 5、生命上限 +2。
- 主要效果：主动进入 `vanillaSnow_deepfreeze_online` 极寒领域，持续 8 秒；每秒消耗 2 点寒势，期间近身敌人获得 4 秒缓慢和每秒 1 点寒冷触伤，冰法命中使冻结时长 +1 秒。窗口结束时若寒势仍不低于 8 点，保留 8 点寒势作为下次启动底火，不自动续期。
- 触发条件：玩家主动施放；寒势不低于 16 点。
- 强联动：霜封心室、冰晶肺叶、白桦髓肝、雪藏脾囊。
- 弱联动：Aquamirae 风暴符文（其寒冷群系增伤由原物品自身负责）。
- 限制 / 代价：不是无消耗爆发，而是持续低温领域；玩家必须在领域内保持冻结梯度。核心不再直接释放 `irons_spellbooks:ice_block`，也不做自定义解冻状态机。
- Synergia 元素点：冰（5）。

## 六、联动链

### 1. 寒潮法斗链

```text
冰晶肺叶 -> 白桦髓肝 -> 寒光冠脑 -> 冰芯节律器 -> 霜寒主核
```

- 冰晶肺叶负责冰法命中产势。
- 白桦髓肝把寒势转成法力。
- 寒光冠脑把主场冰面转成施法节律。
- 冰芯节律器让寒势在结晶和消融之间维持节奏。
- 霜寒主核把持续寒势转成极寒领域，而不是一次性 Ice Block。

### 2. 冰裂反打链

```text
冻裂髓鞘 -> 凝华导管 -> 霜封心室 -> 霜寒主核
```

- 髓鞘负责受击/冰法命中蓄势。
- 凝华导管把高寒势转成抗冻结与冰壳稳定。
- 心室负责生命与冻结抑制。
- 主核负责把寒势网络接入极寒领域。

### 3. 雪盲压制链

```text
冰碴臂束 -> 霜脉束 -> 雪盲虹膜 -> 霜蹄腿腱
```

- 臂束近战上标。
- 霜脉束把标记和追击连接起来。
- 虹膜远程吃标并延长压制。
- 腿腱负责雪地追击和拉扯距离。

### 4. 寒地打捞链

```text
雪藏脾囊 -> 霜蹄腿腱 -> 冻土胸甲膜
```

- 脾囊负责雪/冰采集和冰迷宫猎杀资源。
- 腿腱负责寒地移动。
- 胸甲膜负责在船/哨站/庇护所附近站场，把探索变成稳定的资源回收线。

### 跨来源弱联动

- Aquamirae 三栓潜水服保留原生冰迷宫防冻，不与器官冻结抑制叠加成免疫。
- Aquamirae 风暴符文保留原生寒冷群系 +33% 伤害，仅供霜寒主核后期构筑参考，不重写为器官词条。
- Ice and Fire 雄性冰龙继续作为高阶级解剖来源，产出霜封心室和寒光冠脑，不新增龙息等异源头强联动。
