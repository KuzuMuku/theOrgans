### 核心定位

这套系统对应 **原版海洋群系系列** 的器官路线。  
它不是雨林、沼泽或雪原那种陆地主场，而是一套明显带有 **潮汐、水压、盐雾、海草、珊瑚、鱼群、沉船与海洋神殿** 气味的深海生体体系。

它的主要职责有四条：

- **潮汐生存**：在水下、雨天、海边和航海环境里维持生存、回复和稳定施法。
- **深海机动**：把水域变成自己的移动主场，不被减速、溺水和击退拖死。
- **海神殿压制**：围绕守卫者、远古守卫者、海晶石与海晶灯做一条明确的结构压制线。
- **打捞成长**：把捕鱼、海兽击杀、沉船与海底采集转成资源收益。

这意味着它不该走纯近战硬顶，也不该做成纯炮台。  
它应该是一套 **能下海、能游走、能打捞、能在神殿里站住** 的海洋综合体系。

---

### 核心循环与设计哲学

这套海洋器官的哲学是：**先适应水压，再扩展航线，最后把海域变成你的补给区。**

对玩家真正重要的状态有三种：

- **潮汐活性**：代表器官是否处在水域或雨天主场。
- **海压储能**：代表在水下、受击、游泳、命中海洋目标时积累的稳定收益。
- **神殿回响**：代表海洋神殿与深海结构带来的压制、识别和结构奖励。

体验上，它应该有以下手感：

- 一进水就明显比陆地更顺，不会像别的体系那样下水就失速。
- 你不是靠爆发秒杀，而是靠水下压制、拖拽、持续命中和稳定回收打优势。
- 海洋相关法术和效果不是“神秘蓝光”，而是 **潮声、气泡、盐雾、珊瑚碎光、深海回流**。
- 海洋、海滩、暖海、深海、冰冻海和海洋神殿都能提供对应收益，但基础能力离开主场也不会失效。

### 器官列表（建议 20 个）

建议配比：

- **辅助器官 12 个**
- **功能器官 8 个**

这样海洋会先有足够的水下生存、续航和结构底盘，再由少量功能器官补足压制、机动和资源回收，不会变成全是花活的功能堆。

#### 一、核心与生存器官

**1. 潮汐心室**
- **外观**：心脏外包着一层缓慢涨落的蓝白水膜，像被潮水托住。
- **功能**：整套体系核心。提供基础生命、少量护甲和水域稳定性；在水中、雨天或海边进一步增强。
- **设计思路**：这是“下海也不虚”的底盘，不追求爆发，追求海域适应力。

**2. 盐鳃肺叶**
- **外观**：肺部边缘长出细密鳃膜和盐晶纹路，呼吸时会吐出微泡。
- **功能**：提供水下呼吸、少量 `max_mana` 和 `mana_regen`，并让水下施法更顺滑。
- **设计思路**：让海洋法斗不必先解决溺水问题。

**3. 深海肝囊**
- **外观**：肝脏表面像储着一团深蓝海水，内部有缓慢游动的细小鱼影。
- **功能**：提供 `max_mana`、`mana_regen`，并在吃鱼类食物、处于水中或击杀海洋生物时加强续航。
- **设计思路**：海洋法师的法力来自海产和潮汐代谢，而不是纯净奥术容器。

**4. 珊瑚骨板**
- **外观**：胸腹和肩背长出珊瑚状骨板，边缘带有亮色礁纹。
- **功能**：提高护甲、护甲韧性和击退抗性；在水中或靠近海洋方块时额外稳定。
- **设计思路**：它负责把海域的“礁体感”做成真正的站场资本。

**5. 海流脾囊**
- **外观**：脾脏外长出数个鼓起的气囊，像一团会跟着潮汐收缩的浮袋。
- **功能**：资源辅助器官。提高捕鱼、海洋生物击杀、贝壳/海晶/珊瑚类采集的收益。
- **设计思路**：海洋不只是战斗场，也是一条稳定打捞线。

**6. 潮压冠脑**
- **外观**：头颅外侧覆盖一圈深蓝神经冠，像海面下的压力环。
- **功能**：提升 `cooldown_reduction`、`knockback_resistance`，并让水下和雨天的施法更稳定。
- **设计思路**：它负责把海压转换成节奏优势。

#### 二、水下机动与感知器官

**7. 湿鳃颊囊**
- **外观**：脸侧和颈侧长出半透明鳃囊，收缩时会冒出细泡。
- **功能**：提升水下移动和转向能力；进入水域后短时间获得更强的追击与脱离能力。
- **设计思路**：海洋体系不能只会抗，必须能游。

**8. 海镜虹膜**
- **外观**：眼睛表面像覆着一层浅蓝玻璃，能反射水面和海底微光。
- **功能**：提高水下视野、夜视和投射物命中稳定性；对海洋目标更容易保持锁定。
- **设计思路**：海里打架最怕看不清，这个器官负责“看得见”。

**9. 浮沫肾囊**
- **外观**：腰侧挂着两枚轻盈的气泡状肾囊，走动时会轻轻晃动。
- **功能**：减少溺水压力和环境消耗；在水中、雨天或游泳时提供少量恢复。
- **设计思路**：它是水域续航的保险件。

**10. 远航脚蹼**
- **外观**：脚踝与脚掌延展出柔韧脚蹼，边缘带着细小盐纹。
- **功能**：提高水中移动速度和起跳追击能力；在海边、浅海和潮湿地表也有补偿。
- **设计思路**：让海洋主场不只是站着挨打，而是真能追出去。

**11. 海藻脊髓**
- **外观**：脊柱外缠着海藻状纤维和细细水草丝，像会摆动的神经束。
- **功能**：增强水域中的法术稳定性、施法速度和小幅回复。
- **设计思路**：海底施法要像被海草托着，而不是被水压卡住。

**12. 贝鸣耳蜗**
- **外观**：耳部包着贝壳形骨环，轻触时像能听见很远的潮声。
- **功能**：提高附近敌人的感知和定位能力，对水中目标的命中与追踪更稳定。
- **设计思路**：它负责海战里的“声呐感”。

#### 三、海神殿压制与功能器官

**13. 逆流臂束**
- **外观**：前臂肌束被潮纹和逆向水脉替代，挥动时像在切开水流。
- **功能**：近战命中后附加击退压制或短时减速；在水中命中时效果更强。
- **设计思路**：海洋近战不讲莽撞，讲把对手推回水压里。

**14. 潮涌腿鳍**
- **外观**：小腿与跟腱扩展成更宽的鳍状结构，摆动时会拖出水线。
- **功能**：提供短距离冲刺、转向和水下突进能力。
- **设计思路**：它是海战的移动器官，简单、直接、好实现。

**15. 泡浪喉囊**
- **外观**：喉部挂着几个会吐泡的囊泡，张合时会喷出细小水雾。
- **功能**：近距离范围压制器官。可对贴身敌人施加缓慢、虚弱或命中压制倾向效果。
- **设计思路**：这是海洋版的贴身干扰器官。

**16. 珊刺拳峰**
- **外观**：拳骨外侧长出珊瑚刺状突起，击打时会带出碎屑。
- **功能**：近战命中后叠加少量额外伤害或短时潮湿压制；对水生目标更有压制感。
- **设计思路**：把“珊瑚刮擦感”做成简单可实现的命中强化。

**17. 海神殿折光眼**
- **外观**：眼球周围有一圈海晶色折光膜，像从海晶灯里取出的镜面。
- **功能**：海洋神殿专用功能器官。在守卫者、远古守卫者、海晶石、海晶灯附近提升战斗稳定性和标记能力。
- **设计思路**：这是这套体系的结构专精点，明确服务海神殿。

**18. 潮声叉腕**
- **外观**：手腕与前臂像嵌了一截短叉，动作时会甩出潮声。
- **功能**：适配投掷、叉刺或近战命中后的追击效果；在水中更容易完成二次压制。
- **设计思路**：简单表现“海叉 / 三叉戟式”战斗感，不做复杂武器判定也能落地。

**19. 深潮拾荒手**
- **外观**：手指关节粗大，指缝间卡着细小贝壳和海砂。
- **功能**：资源功能器官。提高捕鱼、击杀海洋怪物、打捞沉船/海底遗迹的收益。
- **设计思路**：把海洋成长路线和资源回收绑在一起。

**20. 珊潮尾椎**
- **外观**：脊尾部形成一段短短的珊瑚尾椎，边缘带着锋利潮纹。
- **功能**：受击后短时间提高下一次攻击的压制力或击退力；水中触发更明显。
- **设计思路**：它负责海洋体系的反打收尾。

### 推荐联动范式

#### 1. 潮汐生存链

`潮汐心室` + `盐鳃肺叶` + `深海肝囊` + `浮沫肾囊`

- 心室提供生命底盘。
- 肺叶解决水下呼吸和基础施法顺滑。
- 肝囊负责回蓝和海产续航。
- 肾囊负责溺水压力与环境恢复。

这条链的目标是：**先能下海，再谈强度。**

#### 2. 深海机动链

`湿鳃颊囊` + `远航脚蹼` + `潮涌腿鳍`

- 颊囊负责游动和转向。
- 脚蹼负责海面、浅海和水下移动速度。
- 腿鳍负责短距冲刺和追击。

这条链的目标是：**在水里比敌人更像鱼。**

#### 3. 海神殿压制链

`珊瑚骨板` + `潮压冠脑` + `海神殿折光眼` + `逆流臂束`

- 骨板负责站住。
- 冠脑负责把海压转成节奏优势。
- 折光眼负责神殿专精。
- 臂束负责把命中转成击退和减速压制。

这条链的核心是：**海神殿不是副本背景，而是你的主场据点。**

#### 4. 打捞资源链

`海流脾囊` + `海镜虹膜` + `深潮拾荒手`

- 脾囊把海洋行为转成成长收益。
- 虹膜提高下水后的识别和命中稳定性。
- 拾荒手把捕鱼、海怪和遗迹打捞转成额外材料。

这条链会让玩家清楚感到：**海洋不是只有战斗，还有经济循环。**

#### 5. 海战法斗链

`海藻脊髓` + `泡浪喉囊` + `珊潮尾椎` + `潮声叉腕`

- 脊髓负责水下施法稳定。
- 喉囊负责贴脸干扰。
- 尾椎负责受击后的短时反打。
- 叉腕负责把近战或投掷动作做成连续压制。

它不是陆地法师，而是典型的 **海战法斗**。

### 数值与效果方向建议

如果后续要把这份计划书落成 OEP / KubeJS 数据，建议优先使用以下方向：

#### 生存与站场

- `minecraft:generic.max_health`
- `minecraft:generic.armor`
- `minecraft:generic.armor_toughness`
- `minecraft:generic.knockback_resistance`
- `minecraft:generic.movement_speed` 少量补偿
- `heal`
- `apply_mob_effect` 做水肺、潮涌、夜视、抗性、缓慢等简洁效果

#### 海洋施法与续航

- `irons_spellbooks:max_mana`
- `irons_spellbooks:mana_regen`
- `irons_spellbooks:cooldown_reduction`
- `irons_spellbooks:cast_time_reduction`
- `irons_spellbooks:casting_movespeed`

#### 海洋环境触发条件

- `biome` / `biome_tag` 绑定海洋、深海、暖海、冰冻海、海滩
- `weather` 绑定雨天和雷暴
- `environment_state` 绑定 `wet`、`in_water`、`underwater`
- `movement_state` 绑定游泳、潜行、冲刺
- `block_tag` 绑定海草、海晶、珊瑚、沙子、岩礁、海晶灯、海晶石
- `nearby_entity` 表现“鱼群越密、回响越强”

#### 推荐事件与执行链

- `attack` / `deal_damage`
  用于“近战命中后挂潮湿压制”“水中命中后额外击退或减速”
- `attacked` / `health_loss`
  用于“受击后生成海压点数”“挨打后短时提高抗性或反打力”
- `enter_water` / `swim_start`
  用于“进入潮汐活性状态”
- `fish_catch`
  用于“打捞成长和海流脾囊收益”
- `spell_cast` / `spell_hit`
  用于“把海洋法术转成回蓝、潮压或短时稳定”
- `biome_change`
  用于“进入海洋群系后补一层基础活性”

这些触发都能直接压在现成的 `biome`、`weather`、`environment_state`、`movement_state`、`block_tag`、`nearby_entity`、`attack`、`deal_damage`、`attacked`、`health_loss`、`fish_catch`、`spell_cast`、`spell_hit`、`apply_mob_effect`、`heal` 上，不需要复杂的状态机或难维护的自定义流程。  
如果后续不想做显式“海压层数”，也可以直接用 `runtime` 点数表示，并在 tooltip 里解释为潮汐储能。

### 明确不建议的方向

- **不要把它写成纯水肺工具。**
  海洋体系的重点是战斗、机动和打捞，不只是溺水免疫。

- **不要把它写成纯海怪杀手。**
  这套器官要能在海里长期运转，而不是只针对守卫者。

- **不要把海神殿做成唯一强度来源。**
  基础水下能力必须常驻，神殿只是结构专精放大器。

- **不要脱离原版海洋元素。**
  命名和视觉应尽量围绕潮汐、盐雾、珊瑚、海草、贝壳、鱼群、沉船、海晶石和海洋神殿展开。

### 首批落地优先级

如果后续要先做第一版，我建议优先保留这 8 个器官：

- 潮汐心室
- 盐鳃肺叶
- 深海肝囊
- 珊瑚骨板
- 海流脾囊
- 潮压冠脑
- 湿鳃颊囊
- 远航脚蹼

这一版已经足够形成两条清晰路线：

- **深海生存机动流**
- **海洋神殿压制打捞流**

等第一版跑顺之后，再补 `海神殿折光眼`、`深潮拾荒手`、`潮声叉腕` 和 `珊潮尾椎`，把结构专精和资源回收补完整，会更稳。
