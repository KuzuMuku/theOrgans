# 原版繁茂洞穴实现稿（vanillaLushCaves）

## 一、文档定位与取舍标准

本文是 `theOrgans/organs/vanillaLushCaves/design-vanilla-lush-caves.txt` 的下游取舍稿，对标幽匿 `vanillaShulk实现方案.md` 的完成度。它的职责不是把设计稿再扩写一遍，而是确定每个器官最后到底做成什么、从哪里获得、消耗什么、触发什么事件。

保留：

- 来源与主场：原版 `minecraft:lush_caves` / 蘑菇与真菌群系 / 低光植被洞穴 / 苔藓与菌床环境不变。
- 基础面板：现有 JSON 的生命、护甲、韧性、魔力等基础属性不改。
- 功能宽度：保留当前已经落地的 10 个常规器官，不为了“精简”删掉法力件或资源件。
- 视觉主题：苔藓、发光浆果、孢子花、垂根、黏土、方解石、菌床、菌丝、洞内微光。

收敛：

- 核心资源只保留 `孢光共生度`，运行时继续使用 `kubejs:vanillaLushCaves_resonance`，不再拆出“孢种层数 / 孢光活性 / 萌发生命力”三套平行文案。
- 玩法从“攒共振、半量释放”改成“播孢、菌丝连接、孢子花区维持”。资源会随着花区存在而持续消耗，离开菌床/花区会缓慢回落。
- 补入 `菌丝桥`、`孢囊导管`、`荧光菌床`、`共生根网` 四类自然辅助件，承担类似机械系“线路/管道”的连接和分配职责。
- 每个器官只承担“面板底盘、播孢、连接、花区维持”中的一种主要角色，删除“回血、回蓝或短时法强”之类的多候选写法。
- 不把繁茂洞穴写成丛林藤蔓前排，不写成沼泽毒系，也不做成纯奶妈；它是三套自然系里的“区域共生与铺场”来源。

### 主场条件

- 维度：`minecraft:overworld`。
- 群系：`minecraft:lush_caves`、`regions_unexplored:fungal_fen`、`regions_unexplored:bioshroom_caves`。
- 结构：`betterdungeons:skeleton_dungeon`、`betterdungeons:zombie_dungeon`。
- 不再使用“附近有苔藓、菌丝、发光浆果、杜鹃树”等方块邻近判定。

## 二、内容模块清单

以下内容来自仓库内已落地的器官 JSON、掉落配置、手术配方、Regions Unexplored 配置和本地中文语言文件，不额外虚构原版结构中不存在的专属建筑。

### 原版发光洞穴基底地形与结构

- 入口层：杜鹃树、盛开的杜鹃树、根土、苔藓块与苔藓地毯，用于标记地表洞穴入口。
- 洞内基底：开阔洞穴、含水层与水池、黏土沉积、方解石、滴水石与尖柱，构成“洞内主场”的地形来源。
- 植物层：孢子花、发光浆果与洞内藤蔓、大小垂滴叶、苔藓块与苔石、菌丝样植被。
- 生物层：美西螈、发光鱿鱼、蝙蝠。三者的解剖掉落分别对应回春肝、浆囊/脾囊、足垫。
- 结构层：原版繁茂洞穴没有专属建筑，因此不虚构“繁茂神殿”。结构语义由地表杜鹃树入口、洞内嵌式地下结构与当前整合包里确认存在的 Better Dungeons 地牢承担。

### 已确认的整合包模组映射

| 模块 | 内容 | 用途 |
|---|---|---|
| Better Dungeons | `betterdungeons:skeleton_dungeon` / `zombie_dungeon` 的普通与特殊宝箱 | 垂根束臂、孢芽腺团、孢光肺叶的宝箱来源 |
| Bosses of Mass Destruction | `bosses_of_mass_destruction:gauntlet` | 苔光心核的解剖来源 |
| Bosses of Mass Destruction | `bosses_of_mass_destruction:void_blossom` | 幽苔冠脑的解剖来源，也是新增孢苞主核的毕业来源 |
| Regions Unexplored | `regions_unexplored:fungal_fen` | 已命中现有 `fungal` 主场关键字，可做真菌地表扩展 |
| Regions Unexplored | `regions_unexplored:bioshroom_caves` | 需要把 `bioshroom` 显式加入主场关键字后纳入；发光生物蘑菇块可挂到微光判定 |
| Regions Unexplored | `regions_unexplored:prismachasm` | 只作为棱彩苔藓、棱彩石、发光生物蘑菇块的可选视觉/微光扩展，不作为第一版大范围主场 |
| 器官手术 | 基础器官、方解石、苔藓块、退火方解晶片、孢荧药浆、洞辉菌核、1000 mb 奶 | 钙脉胸骨的手术配方来源 |

`Regions Unexplored` 的红石洞穴、灼热洞穴、远古三角洲不进入本系来源，避免把同一模组里不相干的地下群系硬塞进繁茂洞穴身份。

### 非器官辅助件

繁茂洞穴的自然辅助件是一套“菌丝网络”，而不是把每个器官都做成独立充电件：

| 辅助件 | 定位 | 设计作用 |
|---|---|---|
| `菌丝桥` | 共生线路 | 把附近孢子花区连接起来；每个连接使花区持续时间 +2 秒，效果半径 +1 格 |
| `孢囊导管` | 孢子管道 | 每秒向指定花区输送 1 点孢光共生度 |
| `荧光菌床` | 环境节点 | 让洞穴地面成为花区生根点；花区内自然法命中伤害 +2，生命恢复 +1 |
| `共生根网` | 团队连接 | 让站在花区内的盟友每 2 秒恢复 1 点生命，击退抗性 +1 |

这些辅助件让繁茂洞穴的核心动作不是“攒满资源后打一发”，而是“选择在哪里铺开花区，并让菌丝网络继续养住它”。

## 三、孢光共生度闭环

孢光共生度是整套体系唯一可积累、可消耗的资源。它同时承担“孢子播撒后的生命活性”和“菌丝网络需要维护的共生营养”两层语义，但实际做成一个 counter，不做复杂多状态机。

- 上限：苔光心核 +50，亮苞浆囊 +8。
- 产共生：孢光肺叶（自然法命中播孢，并给附近花区 +1）、洞苔回春肝（命中 +1 / 受击 +2）、孢芽腺团（受击 / 击杀各 +1）、垂根束臂（命中 +1）、菌丝足垫（每移动 2 格 +1）、亮苞浆囊（自然施法 +2）、孢床脾囊（挖掘 / 自然法命中各 +2）。
- 耗共生：孢床脾囊的额外补给 roll 消耗 2 点；孢苞主核开启花区后按持续时间消耗，不半量清仓。
- 花区语义：`孢囊导管` 把共生度送入附近花区；`菌丝桥` 延长连接；`荧光菌床` 决定花区能否继续存在；`共生根网` 把花区收益分给盟友。
- 最低启动阈值：现有 `vanillaLushCaves_resource_online` 保留“至少 8 点才算可用储备”的约定，避免低储量空转。

最终稿必须补齐消耗端。如果暂时保留现有孢床脾囊 JSON 的“事件后直接给物资”，在正式收敛稿里也要把额外补给改成消耗 2 点孢光共生度，否则整套体系会退回“只进不出”的日志。

## 五、新增核心器官：孢苞主核

- 物品 ID：`kubejs:sporebloom_core`
- 来源：解剖 `bosses_of_mass_destruction:void_blossom` 的胸部槽位，作为繁茂洞穴线的毕业主动件。
- 定位：花区铺场的核心终端。它不是把资源一次性打出去，而是在脚下维持一个短暂孢子花区。
- 面板：常驻 `max_health +4`、`armor +2`、`nature_spell_power +2`、`organsynergia:grass_affinity +4`；提供主动技能 `kubejs:sporebloom_core`。
- 技能：冷却 200 tick，`castEvent` 使用 `sporebloom_core_cast`，最低要求当前孢光共生度不低于 16。
- 释放流程：
  1. 开启 `vanillaLushCaves_spore_bloom`，在自身位置生成持续 10 秒的孢子花区。
  2. 花区存在期间，每秒消耗 2 点孢光共生度；不足时花区提前凋谢。
  3. 花区内玩家和盟友每 2 秒恢复 1 点生命，`nature_spell_power +2`，击退抗性 +1；进入花区的敌人获得 4 秒发光与 3 秒缓慢。
  4. `菌丝桥` 可将花区连接到附近已有菌丝节点，每个连接使持续时间 +2 秒、半径 +1 格；`孢囊导管` 可每秒向花区注入 1 点共生度。

不再调用半量资源决定 `stomp` 等级的通用模板。初始花区出现时可以使用一次短促的 `stomp` 视觉/击退作为“菌床绽开”的落地反馈，但它不是核心结算，也不决定花区强度。

## 六、负面抑制与综合增强

### 负面抑制

- 低光不写成纯 debuff：苔光心核、钙脉胸骨、孢光肺叶把低光植被环境识别为主场窗口，而不是让玩家必须用火把“跳过本系器官”。
- 受击与复杂地形不白吃：洞苔回春肝把受击转成短治疗和花区共生度，菌丝足垫与钙脉胸骨把洞内奔走、击退压力转成机动力和击退抗性。
- 不新增孢子致盲、孢子毒、粉尘窒息等伪负面。繁茂洞穴的负面抑制语义通过现有“环境窗口 + 受击转换 + 地形成压”完成。

### 综合增强

- 法术：`nature_spell_power`、`max_mana`、`mana_regen`、冷却缩减、施法时间缩减、施法移速。
- 生存：`max_health`、`armor`、`armor_toughness`、`knockback_resistance`、短治疗与再生。
- 战斗：近战额外损伤、标记与缓慢、攻击力、洞内机动。
- 资源：发光浆果、苔藓、黏土、孢光共生度与结构掉落来源。

## 七、联动链

### 孢子共生链

`苔光心核` + `洞苔回春肝` + `孢床脾囊` + `孢苞主核`

心核管容量，回春肝把受击 / 命中转成花区补充，脾囊把挖掘和自然法命中转成洞穴补给，孢苞主核生成并维持花区。这条链是“先播撒、后开花、再回收”的最终闭环。

### 地下自然法链

`孢光肺叶` + `亮苞浆囊` + `幽苔冠脑` + `孢芽腺团`

肺叶管自然法强和命中播孢，浆囊管蓝量与施法回蓝，冠脑管冷却与节律，腺团管受压与击杀时给花区补共生度，最后由孢苞主核生成花区。

### 菌丝近战链

`孢芽腺团` + `垂根束臂` + `菌丝足垫` + `钙脉胸骨`

腺团与束臂把命中转成近战压制和标记，足垫负责贴脸与脱身，胸骨负责站住不被打出节奏。

### 洞穴探索链

`苔光心核` + `钙脉胸骨` + `菌丝足垫` + `孢床脾囊`

心核与胸骨保证长期下洞的生存底盘，足垫解决复杂地形，脾囊把挖掘行为转成持续补给。

## 八、Synergia 元素点

现有 10 件全部使用 `organsynergia:grass_affinity`：

- 苔光心核 3、钙脉胸骨 2、孢光肺叶 6、洞苔回春肝 2、孢芽腺团 3、垂根束臂 3、菌丝足垫 1、亮苞浆囊 4、孢床脾囊 2、幽苔冠脑 4。
- 合计 30 点；新增孢苞主核 +4 后为 34 点。

不要给这套器官混入毒、污染、黑暗或机械元素点，保持在木 / 草系共生方向。

## 九、避免问题与落地限制

- 不得让孢床脾囊同时承担回血、回蓝和自然法强。它只做“采集补给 + 花区补共生”的资源角色，恢复归洞苔回春肝与孢苞主核。
- 不得让每个器官都直接给玩家产共生度。固定来源是肺叶、肝、腺团、束臂、足垫、浆囊、脾囊；其余器官只负责面板、窗口或花区维持。
- 不得让孢光共生度成为纯日志。至少要有孢床脾囊的 2 点耗源和孢苞主核按秒持续消耗的花区。
- 不得把茂密植被做成毒系或酸系。自然法术的主题是孢伤、发光、缓慢、标记、回春，不引入沼泽污染。
- 不得把 `bioshroom_caves`、`fungal_fen` 之外的所有 RU 洞穴群系都算作主场。红石、灼热、远古三角洲不进入本来源。
- 不得使用不存在的法术或结构。孢苞主核只把 `irons_spellbooks:stomp` 作为花区绽开时的短促视觉/击退；繁茂洞穴结构语义使用“杜鹃树入口 + 洞内嵌式地下结构 + Better Dungeons 宝箱”，不虚构专属建筑。
- 保持实现复杂度边界：全部使用 counter、runtime、mark、既有事件和 Iron's Spells 主动技能，不引入可编程序列或跨来源强联动。
