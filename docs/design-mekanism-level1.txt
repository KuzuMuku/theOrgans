### 核心目标

这套计划书对应 `Mekanism.T1` 来源的器官组，是一套独立成立的工业义体体系。  
它要回答的问题很明确：

- 来源：`Mekanism` 的基础工业、热能、气体与矿物处理。
- 加成主题：`高科技`，但主题只负责抬方向，不吞掉来源身份。
- 主要流派：`高频压制近战` 与 `工业增产资源`。
- 核心资源：只保留一条 `当前能量 / 能量上限` 读数。

T1 的任务不是把工业系统做复杂，而是把“能充能、能放热、能回收、能增产”这条工业战斗与成长路线跑通。

---

### 核心思路

Mekanism T1 的体验应当接近它本体基础工业阶段的感觉：

- 平时靠基础电力、热量回收和气体循环把系统慢慢抬起来。
- 核心器官负责把零散能量存成可消费的工业储备。
- 输出器官负责把储备转成高频压制、热伤、穿甲或磁轨打击。
- 资源器官负责把能量换成矿物增产、熔炼增益和气体回收。

因此 T1 的边界也要写死：

- 不拆成多条并行资源。
- 不做复杂工序编排。
- 不让单个器官同时承担输出、防御、机动、增产四份职责。
- 复杂感只来自“充能链”“放热链”和“回收链”的组合。

---

### 来源定位与流派边界

来源：`Mekanism.T1`

主要流派：

- `高频压制近战`
- `热能穿甲近战`
- `工业增产资源`

输出 / 成长方向：

- 近战：高速打击、护甲穿透、热伤、磁轨突进
- 资源：矿物增产、气体回收、熔炼收益

不承担的方向：

- 不主打法术
- 不主打复杂机械编排
- 不主打能量护盾、纳米强化或终局锁定

### 当前建议保留的 14 个核心件

#### 一、驱动器官

**1. 工业能核**
- 主要流派：全部 Mekanism T1 流派共用核心
- 输出 / 成长方向：充能底盘
- 主要效果：提供基础能量上限，并储存其他器官输入的工业储备
- 触发条件：常驻
- 强联动：`热泵循环肺`、`气体回流囊`
- 弱联动：全部 Mekanism 消耗器官
- 限制 / 代价：自身不直接提供明显输出

**2. 热泵循环肺**
- 主要流派：热能穿甲近战 / 工业增产
- 输出 / 成长方向：驱动 / 回充
- 主要效果：在持续移动、受击或高温环境下缓慢回充能量，并把一部分热量转成稳定储备
- 触发条件：移动、受击、温热环境
- 强联动：`工业能核`
- 弱联动：`磁轨腿`、`热刃臂`
- 限制 / 代价：寒冷环境回充变慢

**3. 气体回流囊**
- 主要流派：工业增产 / 稳定续航
- 输出 / 成长方向：驱动 / 续航
- 主要效果：把战斗或加工中产生的零散收益回流成少量能量，维持低成本循环
- 触发条件：击杀、挖掘、加工、持续运转
- 强联动：`工业能核`
- 弱联动：全部资源器官
- 限制 / 代价：回流比例低，不能替代正经充能

#### 二、辅助增益器官

**4. 高频稳相耳蜗**
- 主要流派：高频压制近战 / 工业增产
- 输出 / 成长方向：辅助增益
- 主要效果：在连续攻击、挖掘或移动时建立稳定节拍，提升命中稳定性、加工成功率和能量利用率
- 触发条件：连续动作、节奏维持
- 强联动：`热刃臂`、`磁轨拳峰`
- 弱联动：全部 Mekanism 主动器官
- 限制 / 代价：节奏被打断时收益明显回落

**5. 导热骨板**
- 主要流派：热能穿甲近战 / 工业增产
- 输出 / 成长方向：辅助增益
- 主要效果：提高热类器官的放热效率，并降低连续运转时的能量空耗
- 触发条件：持续输出、持续加工、高温状态
- 强联动：`热刃臂`、`过热散流肩`
- 弱联动：`裂解矿囊`
- 限制 / 代价：偏持续收益，不能显著抬高单次爆发

**6. 电容节律腺**
- 主要流派：高频压制近战 / 热能穿甲近战
- 输出 / 成长方向：辅助增益
- 主要效果：在命中或受击后临时提高下一次能量消耗器官的效率，形成短时间连段窗口
- 触发条件：命中、受击、短时间内再次释放
- 强联动：`磁轨拳峰`、`磁轨腿栓`
- 弱联动：`热刃臂`
- 限制 / 代价：窗口很短，站桩拖慢节奏就会浪费

**7. 精馏滤胆**
- 主要流派：工业增产资源
- 输出 / 成长方向：辅助增益 / 资源
- 主要效果：提高气体回收与副产物筛出质量，让资源链更稳定地产出可用副料
- 触发条件：加工行为、击杀回收、采掘结算
- 强联动：`气体回流囊`、`精炼回收腺`
- 弱联动：`裂解矿囊`
- 限制 / 代价：只强化特定工业副产物，不提供直接战斗收益

**8. 校准透镜眼**
- 主要流派：高频压制近战 / 工业增产
- 输出 / 成长方向：辅助增益
- 主要效果：提高磁轨突进、裂解采掘和重拳命中的稳定性，减少偏移和空放
- 触发条件：主动技能释放前、瞄准、冲刺
- 强联动：`磁轨拳峰`、`磁轨腿栓`、`裂解矿囊`
- 弱联动：`高频稳相耳蜗`
- 限制 / 代价：更偏命中修正，本身不提供明显倍率

#### 三、近战特化器官

**9. 热刃臂**
- 主要流派：高频压制近战
- 输出 / 成长方向：近战
- 主要效果：持续消耗能量维持高速切割，对贴身目标造成稳定热伤与流血式压制
- 触发条件：主动开启 / 持续运转
- 强联动：`工业能核`、`导热骨板`
- 弱联动：`热泵循环肺`、`高频稳相耳蜗`
- 限制 / 代价：烧能量快，续航依赖充能链

**10. 磁轨拳峰**
- 主要流派：热能穿甲近战
- 输出 / 成长方向：近战
- 主要效果：消耗能量打出高频重拳，附带穿甲与短距离震退
- 触发条件：主动技能 / 攻击释放
- 强联动：`工业能核`、`热泵循环肺`、`电容节律腺`
- 弱联动：`高频稳相耳蜗`、`校准透镜眼`
- 限制 / 代价：单次爆发后需要短暂回充

**11. 过热散流肩**
- 主要流派：热能穿甲近战
- 输出 / 成长方向：近战 / 生存
- 主要效果：受击或高热时积蓄过热层数，随后把热量转成一次范围冲击
- 触发条件：受击、过热、连续战斗
- 强联动：`热泵循环肺`、`导热骨板`
- 弱联动：`磁轨拳峰`、`电容节律腺`
- 限制 / 代价：偏反打，不适合单独撑起整套流派

#### 四、资源特化器官

**12. 裂解矿囊**
- 主要流派：工业增产资源
- 输出 / 成长方向：资源
- 主要效果：主动消耗能量，对矿物或原矿执行高效率裂解，提高矿物收益并附带少量副产物
- 触发条件：主动技能 / 挖掘
- 强联动：`工业能核`、`校准透镜眼`
- 弱联动：`气体回流囊`、`精馏滤胆`
- 限制 / 代价：会明显抽低能量，并应有冷却或耐久代价

**13. 精炼回收腺**
- 主要流派：工业增产资源
- 输出 / 成长方向：资源
- 主要效果：在熔炼、粉碎或加工行为中提升成品收益，并把废料转回少量可用材料
- 触发条件：加工行为 / 主动使用
- 强联动：`裂解矿囊`、`精馏滤胆`
- 弱联动：`高频稳相耳蜗`
- 限制 / 代价：只强化加工链，不应变成无条件全局增产

**14. 磁轨腿栓**
- 主要流派：高频压制近战 / 工业增产资源
- 输出 / 成长方向：机动 / 资源
- 主要效果：消耗少量能量进行短距突进；若命中目标或矿脉，可顺带提升后续近战或采掘效率
- 触发条件：主动技能、冲刺、挖掘
- 强联动：`工业能核`、`电容节律腺`、`校准透镜眼`
- 弱联动：`热泵循环肺`、`高频稳相耳蜗`
- 限制 / 代价：更像切入和位移件，不该独立撑起伤害

### 推荐联动范式

#### 1. 充能驱动链

`工业能核` + `热泵循环肺` + `气体回流囊`

- 目标：把工业储备稳定养起来
- 价值：让这套来源先有“能运转”的基本盘

#### 2. 高频压制链

`工业能核` + `高频稳相耳蜗` + `导热骨板` + `热刃臂`

- 目标：把能量持续换成稳定近战压制
- 价值：让 T1 有清晰的贴身输出定位

#### 3. 热能爆发链

`工业能核` + `电容节律腺` + `导热骨板` + `磁轨拳峰` + `过热散流肩`

- 目标：用储备换一次明确的穿甲爆发
- 价值：把基础工业义体做成看得懂的爆发节奏

#### 4. 采掘增产链

`工业能核` + `精馏滤胆` + `校准透镜眼` + `裂解矿囊` + `精炼回收腺`

- 目标：形成“前端裂解 + 后端回收”的资源路线
- 价值：让工业来源不只服务战斗

#### 5. 机动切入链

`工业能核` + `电容节律腺` + `校准透镜眼` + `磁轨腿栓` + `热泵循环肺`

- 目标：靠短距机动把输出和采掘都接起来
- 价值：保留科技感，但不做复杂编排

### 落地思路

如果后面把这套计划落成 OEP / KubeJS，建议遵守以下边界：

- `conditions` 负责环境、移动、挖掘、受击等触发门槛
- `grants` 负责基础能量上限、被动属性与静态采掘加成
- `events` 负责充能、过热、回流、节拍维持
- `executions` 负责切割、拳峰、裂解、回收等可见结果

推荐优先实现的事件类型：

- `move`
- `attack`
- `attacked`
- `mine`
- `use_item` / 主动技能事件

### T1 的独立完成度

`Mekanism.T1` 在来源定位上不承担“中间过渡”的职责，而是完整表达一套基础工业义体玩法。  
它的成立条件只有三件事：

- 玩家能靠电 / 热能 / 气体回收把系统稳定运转起来
- 玩家能在近战与资源之间明确选择能量花法
- 玩家能理解这套来源强在工业循环，而不是护盾、纳米或未来科技幻象

因此后续即使存在 `Mekanism.T2`，两者也应当作为并列来源存在。  
T1 负责的是“基础工业如何转成稳定战斗与增产收益”，自身就已经是完整闭环，不需要依赖 T2 才成立。
