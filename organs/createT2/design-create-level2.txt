### 核心目标

这套计划书对应 `机械动力.黄铜` 来源的 T2 器官组，是 `createT1` 之后的升级层。  
它必须延续 T1 已经确认的单资源模型，而不是重新分裂出新资源条。

- 来源：`Create 黄铜阶段` 的精密机械、离合、节拍、稳压和加工升级
- 加成主题：`蒸汽朋克`
- 主要流派：`高压辅助增幅近战`、`稳压采掘资源`
- 核心资源：仍然只有 `当前应力 / 应力上限`

T2 的价值不是“更复杂”，而是“更会蓄、更会抬上限、更会把高压状态变成收益”。

---

### 核心思路

T1 解决的是“能不能把飞轮转起来”。  
T2 解决的是“高压以后怎么花得更值”。

因此这套器官应当围绕三类升级展开：

- `增压件`：让系统更容易蓄满，或者短时间提高应力上限
- `辅助增益件`：不自己承担主要输出，而是强化其他战斗器官和资源器官
- `增产件`：把采掘后的物料通过稳定处理进一步增产

不建议的方向同样需要写死：

- 不做程序器、序列器、编排器官
- 不做多资源互转
- 不让单个器官负责整条工序
- 不靠黑盒操作逻辑制造“高级感”

---

### 来源定位与流派边界

来源：`机械动力.黄铜`

主要流派：

- `高压辅助增幅近战`
- `高压稳定近战`
- `稳压采掘资源`

输出 / 成长方向：

- 近战：重击、突入、破甲、高压增幅
- 资源：钻进、筛分、压榨、加工返利

相对 T1 的升级差异：

- 更高的基础上限
- 更明确的临时上限抬升
- 更稳定的高压区间收益
- 更完整的资源处理链

---

### 建议保留的 10 个核心件

#### 一、核心与增压器官

**1. 黄铜增压心室**
- 主要流派：全部黄铜流派共用核心
- 输出 / 成长方向：蓄压底盘
- 主要效果：提供更高基础应力上限，并允许短时进入增压状态
- 触发条件：常驻
- 强联动：`配重飞轮囊`、`黄铜离合脊`
- 弱联动：全部黄铜应力消耗器官
- 限制 / 代价：自身不直接提供强输出

**2. 配重飞轮囊**
- 主要流派：高压辅助增幅 / 稳压采掘
- 输出 / 成长方向：增压
- 主要效果：在接近满值时继续吃下溢出输入，使系统更容易进入满压或超压
- 触发条件：持续蓄压、高压区间
- 强联动：`黄铜增压心室`
- 弱联动：全部高耗应力器官
- 限制 / 代价：应附带移速、灵活度或操作笨重代价

**3. 黄铜离合脊**
- 主要流派：高压稳定近战 / 稳压采掘
- 输出 / 成长方向：稳压
- 主要效果：减少持续运转类器官的应力浪费，并允许主动泄压避免空放
- 触发条件：高压状态、持续输出状态
- 强联动：`黄铜增压心室`
- 弱联动：`螺旋掘进钻`、`黄铜打桩拳`
- 限制 / 代价：偏稳压时，纯爆发收益会低一些

#### 二、辅助增益器官

**4. 节拍校准耳蜗**
- 主要流派：高压稳定近战 / 采掘增产
- 输出 / 成长方向：辅助增益
- 主要效果：在持续攻击、挖掘或移动时建立稳定节拍，提升黄铜器官命中稳定性、加工成功率或应力利用率
- 触发条件：连续动作、节奏维持
- 强联动：`黄铜离合脊`
- 弱联动：全部黄铜主动器官
- 限制 / 代价：一旦被打断节奏，收益会明显回落

**5. 增压锻炉肺**
- 主要流派：高压辅助增幅近战
- 输出 / 成长方向：辅助增益
- 主要效果：当应力处于高位时，强化近战器官的击退、破甲、灼热或持续伤害收益
- 触发条件：高压区间、近战输出
- 强联动：`黄铜打桩拳`、`棘轮破城肩`
- 弱联动：全部黄铜近战器官
- 限制 / 代价：高压时应附带噪音、仇恨或热量压力

**6. 润滑回流腺**
- 主要流派：高压稳定近战 / 稳压采掘
- 输出 / 成长方向：辅助增益
- 主要效果：降低持续运转类器官的应力损耗，并让泄掉的部分压力回流成少量续航
- 触发条件：持续消耗应力、长时间运转
- 强联动：`黄铜离合脊`、`螺旋掘进钻`
- 弱联动：`黄铜打桩拳`
- 限制 / 代价：偏续航型，不能显著提高单次爆发上限

**7. 配压黄铜膜**
- 主要流派：高压辅助增幅 / 稳压采掘
- 输出 / 成长方向：辅助增益
- 主要效果：在满压或近满压时，给其他黄铜器官提供短时效率加成，例如更高采掘收益、更稳的重击倍率或更低空转损耗
- 触发条件：满压、高压窗口
- 强联动：`黄铜增压心室`、`配重飞轮囊`
- 弱联动：全部黄铜功能器官
- 限制 / 代价：必须先把压力堆高，低压状态近乎无收益

#### 三、功能输出器官

**8. 黄铜打桩拳**
- 主要流派：高压爆发近战
- 输出 / 成长方向：近战
- 主要效果：消耗大量应力打出高伤害重击；若直接抽空全部应力，则触发完整超频打桩
- 触发条件：主动技能 / 攻击释放
- 强联动：`黄铜增压心室`、`配重飞轮囊`、`增压锻炉肺`
- 弱联动：`节拍校准耳蜗`
- 限制 / 代价：自身是爆发终端，强度应明显依赖辅助件抬起来

**9. 棘轮破城肩**
- 主要流派：高压爆发近战
- 输出 / 成长方向：近战 / 突入
- 主要效果：移动、受击或命中时积蓄冲势，在肩撞时把临时压力砸出去并打乱目标站位
- 触发条件：移动、受击、命中、主动撞击
- 强联动：`配压黄铜膜`、`增压锻炉肺`
- 弱联动：`节拍校准耳蜗`
- 限制 / 代价：更像爆发前置和战场切入口，不该独立撑起整套流派

**10. 螺旋掘进钻**
- 主要流派：稳压采掘资源
- 输出 / 成长方向：资源
- 主要效果：持续消耗应力，对前方狭窄区域进行高速定向掘进
- 触发条件：主动技能 / 挖掘
- 强联动：`黄铜离合脊`、`润滑回流腺`
- 弱联动：`节拍校准耳蜗`
- 限制 / 代价：偏向稳定钻进，不应兼顾大范围爆破

### 推荐联动范式

#### 1. 黄铜爆发链

`黄铜增压心室` + `配重飞轮囊` + `配压黄铜膜` + `增压锻炉肺` + `黄铜打桩拳`

- 玩法：先蓄满，再把高压转成增幅，最后由打桩拳收尾
- 目标：强调“辅助件把终端件抬起来”，而不是每件都能单干

#### 2. 高压增幅链

`黄铜增压心室` + `黄铜离合脊` + `节拍校准耳蜗` + `增压锻炉肺` + `棘轮破城肩`

- 玩法：保持高应力和动作节拍，把整套近战输出稳定在高效率区间
- 目标：让黄铜阶段出现明显的“辅件流”

#### 3. 采掘增产链

`黄铜增压心室` + `黄铜离合脊` + `润滑回流腺` + `配压黄铜膜` + `螺旋掘进钻`

- 玩法：用稳压和回流降低空耗，再用满压窗口抬高钻进收益
- 目标：资源流同样依赖辅助件，而不是只有一把钻头

### 落地思路

如果后面把这套计划落成 OEP / KubeJS，建议重点把复杂度放在“区间判定”和“辅助加成”上，而不是“操作编程”上：

- `conditions`：高应力区间、满压、移动、受击、挖掘、加工
- `grants`：基础上限、被动增幅、辅助加成、稳定采掘收益
- `events`：临时上限积累、蓄压、泄压、节拍维持
- `executions`：打桩、肩撞、钻进

推荐优先实现的效果类型：

- 高应力区间增伤 / 破甲 / 效率提升
- 临时提高应力上限
- 应力损耗减免与泄压回流
- 辅助器官对主动器官的增益

---

### 第一版落地优先级

如果要压缩实现范围，第一版建议只保留 8 个器官：

- 黄铜增压心室
- 配重飞轮囊
- 黄铜离合脊
- 节拍校准耳蜗
- 增压锻炉肺
- 润滑回流腺
- 黄铜打桩拳
- 螺旋掘进钻

这版已经足够形成两条非常清楚的路线：

- `高压辅助增幅近战`
- `稳压采掘资源`

等这两条路线跑顺，再补 `配压黄铜膜` 和 `棘轮破城肩` 去强化满压爆发窗口，会更稳。
