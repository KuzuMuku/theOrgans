# 原版丛林 / 冰与火丛林生态实际落地稿

本文是 [design-vanilla-jungle.txt](/home/kuzuanpa/projects/1.20.1/theOrgans/organs/vanillaJungle/design-vanilla-jungle.txt:1) 的施工图版本。上游概念稿负责回答“丛林体系是什么”：原版丛林地表、丛林神庙、热带植物、豹猫鹦鹉，加上 Ice and Fire 的丛林恐蚁与丛林羽蛇；本文负责回答每个器官最后到底装什么、触发什么事件、消耗什么资源。

实现稿不再沿用“储能 -> 释放 -> 再储能”的通用自然系模板，而是把丛林做成**树液流动与根脉锚定**：

- 保留来源与主场条件，不为了扩题材破坏“原版丛林”身份。
- 保留器官基础面板，只收敛功能类特效，删掉多余堆叠。
- 冠层树液不是蓄能池，而是需要持续流动的成长资源；离开行为和主场会衰减，主场只提高流量。
- 补入 `木质输导管`、`根脉锚丝`、`气根呼吸管`、`藤蔓缠绕束` 四类自然辅助件，承担类似机械系“电线/管道”的连接角色。
- `古树共振核` 改为“古树根脉协议”，持续消耗树液维持根系窗口，不再半量清仓释放一个通用法术。
- Ice and Fire 不单独成为新来源，只作为丛林生态层与高阶猎杀层并入本来源。

## 一、来源与主场

来源定位是：

```text
原版群系.丛林 + Ice and Fire.丛林生态
```

Ice and Fire 的丛林羽蛇、丛林恐蚁、以及可能重叠到丛林热带的火龙内容，都不单独成为新来源。它们保留自己的实体、战利品和世界生成，本方案只从“猎杀、解剖、材料、高压验证”这些器官系统允许的接口吸收。

### 主场条件

保持现有 `vanillaJungle_runtime.js` 的判定不变：

- 主世界（`minecraft:overworld`）。
- 群系关键字包含 `jungle` / `bamboo`，覆盖丛林、稀疏丛林、竹林等原版变体。
- 附近存在 `minecraft:jungle_temple`，结构判定沿用现有 8 chunk 搜索半径。

Ice and Fire 内容不塞进主场判定。丛林恐蚁巢、翼蚺、火龙都以实体过滤、战利品、解剖来源接入，避免把“原版丛林主场”偷偷改成“冰与火模组主场”。

### 四类窗口

继续保留现有四个运行时窗口，它们都是环境条件，不放进第二套计数资源：

- **扎根站场** `vanillaJungle_rooted_window`：丛林群系或丛林神庙结构，且玩家静止 3 秒。
- **湿热雨林** `vanillaJungle_rainforest_window`：丛林群系或丛林神庙结构。
- **缠斗压制** `vanillaJungle_snare_window`：丛林神庙结构。
- **潮湿冠层** `vanillaJungle_canopy_window`：丛林群系。

每个器官只读取与自己的唯一落点相关的窗口，不允许一个器官同时吃四个窗口。

## 二、核心资源与状态

### 1. 冠层树液

保留现有 `kubejs:vanillaJungle_resonance` 与 `kubejs:vanillaJungle_resonance_capacity`，展示名继续叫“冠层树液”：

- 上限来源：板根心室 +50、神庙苔石脊 +20、雨林蓄水囊 +8。
- 生产端：近战命中、被击、移动、采掘、自然法术命中、自然法术施放、湿热生长；辅助件只提高流量，不直接制造第二资源。
- 消耗端：捕蝇花咽囊固定消耗 12 点；古树根脉协议按持续时间消耗，不半量清仓。
- 衰减端：离开主场的普通环境每 30 秒损失 2 点树液；主场不损失，湿热/冠层窗口提高产量。目的是让玩家维持节奏，而不是挂机攒满。
- 阈值端：只读取树液是否足够、是否达到最低启动线，不新增第二个显式资源。

树液不是无限被动收入。每一次生产都必须有行为来源：近战、受击、位移、采掘、自然法术或环境窗口。离开丛林只保留基础能力，主场窗口只负责提高触发收益。

核心玩法不是“攒满一波再爆发”，而是“让树液保持流动”。玩家应当持续战斗、移动、施法或采掘，树液会不断产生并用于维持根脉窗口；停止行为后树液缓慢回落，因此丛林更偏向持续站场与反复拉打。

### 2. 丛林标记

保留现有 `mark:kubejs:vanillaJungle_mark`：

- 上标记：绞藤臂束在缠斗压制窗口内近战命中。
- 吃标记：古树根脉协议和捕蝇花咽囊在窗口内对带标记目标增加短时压制。
- 限制：标记只做战斗锁，不承担经济资源功能；不把上标记、吃标记、伤害倍率全部堆进同一器官。

### 非器官辅助件

丛林不像机械系那样有可见管线，但需要用同样的“连接件”承担资源分配、根脉锚定和冠层供能，避免每件器官都直接产/耗同一个 counter：

| 辅助件 | 定位 | 设计作用 |
|---|---|---|
| `木质输导管` | 树液管线 | 把近战/受击产生的树液导入根脉窗口，提高流量；自身不直接回血 |
| `根脉锚丝` | 根系连接 | 站场、冠层或缠斗窗口在线时，每 5 秒向根脉窗口 +1 树液 |
| `气根呼吸管` | 冠层供能 | 让自然施法与树液流互转，替代“施法命中直接 +2”的单一写法 |
| `藤蔓缠绕束` | 控制连接 | 让标记和短控制可被附近藤蔓器官共同利用，不把标记做成经济资源 |

这些辅助件优先作为手术辅料、固定装配效果或 runtime 谓词，不要求全部占用新的器官槽位。它们的作用是让丛林看起来像“一套根脉网络”，而不是十个互相独立、只在数值上相似的自然器官。

## 五、器官详细词条

### 1. 板根心室 `kubejs:buttress_ventricle`

- 面板：保留现有 `max_health`、`armor`、草亲和与 `vanillaJungle_resonance_capacity`。
- 主要效果：提供冠层树液储量上限；四件丛林器官共振时生命 +2；扎根时护甲韧性 +1；湿热雨林时生命 +1、护甲 +1。
- 触发条件：静态 + `vanillaJungle_set_major` + `vanillaJungle_rooted_online` + `vanillaJungle_rainforest_online`。
- 联动对象：所有树液生产器官、捕蝇花咽囊、古树共振核。
- 限制/代价：只做底盘和容量，不产树液；离开主场只保留基础面板。

### 2. 青苔树皮甲 `kubejs:mossbark_carapace`

- 面板：保留现有 `armor`、`armor_toughness`、草亲和。
- 主要效果：提供护甲与韧性底盘；扎根时生命 +2；湿热冠层时击退抗性 +2。
- 触发条件：静态 + `vanillaJungle_rooted_online` + `vanillaJungle_canopy_online` / `vanillaJungle_rainforest_online`。
- 联动对象：板根心室、神庙苔石脊、孢网冠脑。
- 限制/代价：自然法抗不由它承担，避免和孢网冠脑重复；不做分阶段工序，只把“越站桩越稳”做成简单窗口词条。

### 3. 雨林蓄水囊 `kubejs:rainforest_water_sac`

- 面板：保留现有 `irons_spellbooks:max_mana`、`irons_spellbooks:mana_regen`、树液容量与草亲和。
- 主要效果：自然法术施放时 +2 冠层树液并恢复 4 点法力；湿热窗口额外获得 `mana_regen +1` 和生命 +1。
- 触发条件：`organironspell:spell_cast`，school 为 `irons_spellbooks:nature` + `vanillaJungle_rainforest_online`。
- 联动对象：兰荧法芽肺、孢网冠脑、可可髓回蓝肝。
- 限制/代价：只承担回蓝与施法回响，不做水中回血、游泳增益、水下呼吸等无关词条。

### 4. 神庙苔石脊 `kubejs:temple_moss_spine`

- 面板：保留现有 `armor`、`knockback_resistance`、树液容量与草亲和。
- 主要效果：受击 +3 冠层树液、采掘 +2 冠层树液；扎根时击退抗性 +2，冠层时护甲韧性 +1。
- 触发条件：`attacked` + `mine` + `vanillaJungle_rooted_online` / `vanillaJungle_canopy_online`。
- 联动对象：板根心室、青苔树皮甲、古树共振核、原有丛林神庙战利品入口。
- 限制/代价：采掘资源必须绑定行为来源，不能让树液变成挂机被动收入；若当前 JSON 的 `mine` 事件没有方块过滤，落地时应过滤为植物、藤蔓、苔藓、丛林神庙相关方块或延续现有矿石之外的普通采掘触发，避免和沙漠/地狱的“挖什么都有”模板重复。

### 5. 绞藤臂束 `kubejs:stranglevine_arm`

- 面板：保留现有攻击与草亲和。
- 主要效果：近战命中 +1 冠层树液并对目标施加 `minecraft:slowness`；缠斗压制窗口内命中时给目标上 `vanillaJungle_mark`，命中带标记目标结算 `minecraft:weakness`。
- 触发条件：`deal_damage` + `vanillaJungle_snare_ready`。
- 联动对象：捕蝇花咽囊、豹纹伏地腿腱、兰荧法芽肺。
- 限制/代价：它只负责近战上标记和短时减速；不额外做远程、反伤、嘲讽或弱势放大。

### 6. 捕蝇花咽囊 `kubejs:flytrap_throat_sac`

- 面板：草亲和、缠斗窗口击退抗性、主动技能 `kubejs:flytrap_throat_sac`。
- 主要效果：主动喷出近距离弱化花囊，4.5 格内敌人获得虚弱与缓慢；持续时间为 `80 + 缠斗线 * 20` tick。
- 触发条件：玩家主动施放，消耗 12 点冠层树液。
- 联动对象：绞藤臂束、豹纹伏地腿腱、古树共振核。
- 限制/代价：这是丛林现有的第一个主动技能，不和核心技能互相消耗；不把花囊做成远程直线伤害。

### 7. 豹纹伏地腿腱 `kubejs:jaguar_crouch_tendon`

- 面板：保留现有移动速度与草亲和。
- 主要效果：每移动 2 格 +1 冠层树液；潮湿冠层时移动速度 +1，湿热雨林再获得移动速度 +1、击退抗性 +1。
- 触发条件：`move` + `vanillaJungle_canopy_online` / `vanillaJungle_rainforest_online`。
- 联动对象：绞藤臂束、捕蝇花咽囊、兰荧法芽肺。
- 限制/代价：只做追猎机动，不直接产树液；树液流量来自持续移动，而不是移动计数。

### 8. 兰荧法芽肺 `kubejs:orchid_spellbud_lung`

- 面板：保留现有 `irons_spellbooks:nature_spell_power`、`irons_spellbooks:cast_time_reduction` 与草亲和。
- 主要效果：自然法术命中时给根脉窗口 +1 冠层回响，并向目标周围 4 格释放一次短藤蔓回响：2 点自然追伤 + 3 秒虚弱。
- 触发条件：`organironspell:spell_hit`，school 为 `irons_spellbooks:nature`。
- 联动对象：雨林蓄水囊、孢网冠脑、古树共振核。
- 限制/代价：这是自然法术的输出/回响落点，不回蓝、不增加 max_mana、不做持续毒池。所有法强只指向 `nature_spell_power`，不变成泛用法强。

### 9. 可可髓回蓝肝 `kubejs:cocoa_marow_liver`

- 面板：按设计稿保留 `irons_spellbooks:max_mana`、`irons_spellbooks:mana_regen` 与草亲和。
- 主要效果：近战命中或受击时，湿热窗口内每 2 秒恢复 2 点法力；受击时获得 4 秒再生。
- 触发条件：`deal_damage` + `attacked` + `vanillaJungle_rainforest_online` + 进食行为。
- 联动对象：雨林蓄水囊、孢网冠脑、兰荧法芽肺。
- 限制/代价：现状 JSON 把命中变成了治疗，和名字“回蓝肝”及设计稿不一致。实现稿要求去掉“命中回血 + 受击再生 + 手动治疗”的多路杂糅，只留下“回蓝 + 湿热短再生”一条代谢方向。

### 10. 孢网冠脑 `kubejs:sporeweb_crown`

- 面板：保留现有 `irons_spellbooks:cooldown_reduction`、`irons_spellbooks:nature_magic_resist` 与草亲和。
- 主要效果：自然法术进入冷却时恢复 3 点法力；潮湿冠层时从冠层线获得施法移速。
- 触发条件：`organironspell:cooldown_added`，school 为 `irons_spellbooks:nature` + `vanillaJungle_canopy_online`。
- 联动对象：雨林蓄水囊、兰荧法芽肺、可可髓回蓝肝、古树共振核。
- 限制/代价：只做施法节律与自然抗性，不承担标记、回血、树液生产或大范围控制。

### 11. 古树共振核 `kubejs:ancient_resonance_core`

- 来源：新增核心器官，承接原取舍稿中“古树共振核”的定位。建议加入 `iceandfire:myrmex_queen_jungle` 的解剖掉落，并以 `iceandfire:amphithere_skull`、`iceandfire:amphithere_feather`、丛林蚁甲/蚁脂作为进阶手术材料，让 Ice and Fire 丛林内容有明确的毕业落点。
- 面板：冠层树液容量 +20、`nature_spell_power +2`、草亲和 6。
- 主要效果：主动开启 `vanillaJungle_root_protocol`，持续 8 秒。期间每秒消耗 3 点树液，近身敌人获得 3 秒虚弱与 3 秒缓慢，自身获得 4 秒再生；结束时每剩余 5 点树液恢复 1 点生命。
- 触发条件：玩家主动施放；树液低于 20 点时不生效。
- 联动对象：板根心室、神庙苔石脊、雨林蓄水囊、兰荧法芽肺、孢网冠脑。
- 限制/代价：不复刻整套古树 Boss 技能，只做一个持续根脉窗口；它不半量清空树液，而是把树液变成维护成本，停止供给或树液不足时窗口提前结束。

## 六、联动链

- **扎根肉盾链**：`板根心室` + `青苔树皮甲` + `神庙苔石脊` + `雨林蓄水囊`。
- **缠斗压制链**：`绞藤臂束` + `捕蝇花咽囊` + `豹纹伏地腿腱`。
- **自然施法站场链**：`板根心室` + `兰荧法芽肺` + `可可髓回蓝肝` + `孢网冠脑`。
- **湿热雨林共鸣链**：`雨林蓄水囊` + `可可髓回蓝肝` + `兰荧法芽肺` + `豹纹伏地腿腱`。
- **根脉流动链**：`木质输导管` + `根脉锚丝` + `气根呼吸管` + `藤蔓缠绕束` 负责把树液和窗口连接起来；`板根心室`、`神庙苔石脊`、`雨林蓄水囊` 提供容量；近战、受击、移动和自然法术维持流量；`捕蝇花咽囊` 固定消耗，`古树共振核` 持续消耗。

强联动只发生在丛林内部。`铁魔法.自然` 是加成主题，不是第二个来源；跨来源弱联动只允许通过自然法术主题发生，不允许“任意机械器官增加丛林自然法强”这类乱连。

## 七、复杂度边界

- 不引入第二套独立法术能量，只保留冠层树液。
- 主动技能只保留 `捕蝇花咽囊` 与 `古树共振核` 两个。
- 每个器官只承担“容量 / 流量 / 固定消耗 / 持续窗口”四类中的一类；需要修改现状时删除多余字段，不保留“同一个行为两三个落点”的旧写法。
- `古树共振核` 不得写成“半量清仓 + `spend / 5` 换法术等级”的通用主核。
- 标记只承担近战缠斗提示，不承担远程倍率、树液倍率、追击锁定等额外职责。
- 所有环境窗口只由维度、群系和结构判定，不使用水桶、人工水池、方块邻近或生物密度条件。

## 八、现状核对与落地修正

以下以当前仓库 JSON 与 KubeJS 为底，只列出需要修正的差异：

- `捕蝇花咽囊`、`豹纹伏地腿腱` 已经存在资产、lang、运行时技能和神庙箱获取，不再写“暂缓”。
- `可可髓回蓝肝` 当前 JSON 更接近“命中医治 / 受击再生”，与名字及设计稿冲突；落地时按本文第五节第 9 项统一为回蓝 + 湿热短再生，不再承担树液生产。
- `神庙苔石脊` 当前 JSON 同时携带站场、采掘、受击产树液和攻击增益；实现稿保留“遗迹/采集资源 + 站场稳定”，把与唯一落点冲突的杂项收掉。
- `兰荧法芽肺` 的范围内追伤与虚弱是自然法术命中回响，不是让该器官同时兼任近战和远程控制。
- `古树共振核` 是新增项，需要同步补 `startup_scripts` 技能注册、`organapi` JSON、中英文案、模型纹理与获取来源；技能效果改为持续树液消耗的 `vanillaJungle_root_protocol`，不再使用半量清仓公式。
- 新增辅助件不强制占用器官 JSON；可先作为手术配方、固定装配效果或 runtime 谓词，避免直接增加器官数量。

## 九、最终目标

这套丛林体系应该让玩家一眼看懂：

- 我来自原版丛林，并能在丛林神庙、热带雨林、竹林和潮湿冠层里获得主场。
- 我是前排缠斗 + 自然法坦，不是远程法炮塔，也不是纯奶妈。
- 我的核心资源是冠层树液，它不是用来攒满清仓，而是靠持续战斗、移动、施法和受击维持流动。
- 我的主要出口是捕蝇花咽囊的固定消耗压制，以及古树共振核持续消耗树液维持的根脉窗口。
- Ice and Fire 的丛林恐蚁与丛林羽蛇是这条线的猎杀与毕业材料层，不替代原版丛林来源。

只要这五件事清楚，器官可以保持简单；反过来，即使机制很多，也只是难维护、难平衡、难理解的复杂堆叠。
