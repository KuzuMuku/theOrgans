### 核心目标

这套计划书对应 `Mekanism.T2` 来源的器官组，是一套独立成立的未来义体终局体系。  
它不是 `Mekanism.T1` 的简单升级包，而是来源身份已经明显变化后的另一条线：

- 来源：`Mekanism` 的终局科技、能量护盾、量子充能与纳米强化。
- 加成主题：`高科技`。
- 主要流派：`护盾压制近战`、`过载爆发远程`、`终局资源复制`。
- 核心资源：只保留一条 `当前护盾 / 护盾上限` 读数。

T2 的任务不是再讲工业生产怎么转起来，而是把“护盾即生命线、过载即爆发窗、纳米即终局增幅”这条未来义体路线立住。

---

### 核心思路

Mekanism T2 的体验应当接近它本体后期科技的感觉：

- 平时靠被动充能、环境吸收和击杀回补维持护盾。
- 核心器官负责把护盾变成可攻可守的未来资源。
- 输出器官负责在高护盾或过载窗口中打出锁定、穿透和斩杀。
- 资源器官负责把多余护盾转成充能采集、稀有材料复制和被动发电收益。

因此 T2 的边界也要写死：

- 不回头强调基础工业加工链。
- 不把重点放在热能 / 气体这种前期工业语义上。
- 不让单个器官同时承担输出、防御、位移、复制四份职责。
- 复杂感只来自“护盾维持”“过载窗口”和“纳米执行”的组合。

---

### 来源定位与流派边界

来源：`Mekanism.T2`

主要流派：

- `护盾压制近战`
- `过载爆发远程`
- `终局资源复制`

输出 / 成长方向：

- 近战：高护盾增伤、护盾反击、过载斩杀
- 远程：锁定、穿透、多段弹道
- 资源：充能采集、被动发电、稀有材料复制倾向

不承担的方向：

- 不主打基础工业增产
- 不主打热能 / 气体回收叙事
- 不主打低阶机械感

### 当前建议保留的 14 个核心件

#### 一、核心与护盾器官

**1. 量子护盾核**
- 主要流派：全部 Mekanism T2 流派共用核心
- 输出 / 成长方向：护盾底盘
- 主要效果：提供基础护盾上限，并把整套未来义体的储备统一成护盾资源
- 触发条件：常驻
- 强联动：`等离子膜肺`、`纳米回充巢`
- 弱联动：全部 Mekanism T2 消耗器官
- 限制 / 代价：自身不直接提供明显输出

**2. 等离子膜肺**
- 主要流派：护盾压制近战 / 过载爆发远程
- 输出 / 成长方向：护盾维持
- 主要效果：在移动、冲刺、受击后短时间内持续回充护盾，并在高能环境下提高回充效率
- 触发条件：移动、冲刺、受击、高能环境
- 强联动：`量子护盾核`
- 弱联动：`矢量锁定眼`、`相位切断臂`
- 限制 / 代价：脱离战斗站桩时回充不快，不能当成无条件再生

**3. 纳米回充巢**
- 主要流派：全部 T2 流派通用
- 输出 / 成长方向：续航 / 稳定
- 主要效果：击杀、采集或护盾破裂后生成少量纳米回充，快速补回一段基础护盾
- 触发条件：击杀、采集、护盾破裂
- 强联动：`量子护盾核`
- 弱联动：全部终端器官
- 限制 / 代价：单次回补有限，不能硬顶持续高压消耗

#### 二、辅助增益器官

**4. 过载稳相脊**
- 主要流派：护盾压制近战 / 过载爆发远程
- 输出 / 成长方向：辅助增益
- 主要效果：当护盾接近满值时建立过载窗口，短时间提升全部 T2 输出效率并压缩技能冷却
- 触发条件：满盾、近满盾、连续命中
- 强联动：`量子护盾核`
- 弱联动：全部 T2 主动器官
- 限制 / 代价：过载结束后会掉一段护盾，不能无限常驻

**5. 护盾编织膜**
- 主要流派：护盾压制近战 / 终局资源复制
- 输出 / 成长方向：辅助增益 / 生存
- 主要效果：降低护盾损失时的浪费，把部分掉盾转成后续器官可用的缓冲层
- 触发条件：受击、掉盾、短时连续承伤
- 强联动：`偏折棱肩`、`纳米复制腺`
- 弱联动：`相位切断臂`
- 限制 / 代价：偏防守向，不能直接抬高主动爆发上限

**6. 矢量锁定眼**
- 主要流派：过载爆发远程
- 输出 / 成长方向：辅助增益 / 远程
- 主要效果：为远程攻击建立短时锁定，提升弹道修正、穿透与多段命中稳定性
- 触发条件：瞄准、连续命中、过载窗口
- 强联动：`过载稳相脊`
- 弱联动：`光矛抛射腱`
- 限制 / 代价：更偏终端辅助，不该单独撑起整套输出

**7. 纳米修复网**
- 主要流派：护盾压制近战 / 终局资源复制
- 输出 / 成长方向：辅助增益 / 续航
- 主要效果：在护盾稳定高位时缓慢修复其他 T2 器官的消耗压力，并缩短部分高代价器官的重新启动时间
- 触发条件：高护盾、脱战短窗、连续维持护盾
- 强联动：`量子护盾核`、`纳米回充巢`
- 弱联动：全部高消耗器官
- 限制 / 代价：要求先维持高护盾，低盾时近乎无收益

**8. 棱镜演算脑**
- 主要流派：过载爆发远程 / 终局资源复制
- 输出 / 成长方向：辅助增益
- 主要效果：在过载或复制判定前提供一次演算校正，抬高锁定、复制和穿透判定的稳定性
- 触发条件：主动技能释放前、过载窗口、加工行为
- 强联动：`矢量锁定眼`、`纳米复制腺`
- 弱联动：`光矛抛射腱`
- 限制 / 代价：主要解决稳定性，不直接给高额倍率

#### 三、战斗特化器官

**9. 相位切断臂**
- 主要流派：护盾压制近战
- 输出 / 成长方向：近战
- 主要效果：护盾处于高位时，近战攻击附带相位切割与额外穿透；主动放出一段护盾可进行斩杀式重击
- 触发条件：高护盾、主动技能、近战命中
- 强联动：`量子护盾核`、`纳米回充巢`、`过载稳相脊`
- 弱联动：`护盾编织膜`
- 限制 / 代价：低护盾时收益明显回落

**10. 光矛抛射腱**
- 主要流派：过载爆发远程
- 输出 / 成长方向：远程
- 主要效果：消耗护盾发射可穿透的能量矛；在锁定状态下可触发追加折返或多段穿刺
- 触发条件：主动技能、远程释放、锁定状态
- 强联动：`矢量锁定眼`、`过载稳相脊`、`棱镜演算脑`
- 弱联动：`等离子膜肺`
- 限制 / 代价：爆发明确，但护盾消耗较大

**11. 偏折棱肩**
- 主要流派：护盾压制近战
- 输出 / 成长方向：防御 / 反击
- 主要效果：护盾承受伤害时积蓄偏折层数，层满后把下一次受击或近战碰撞转成范围反射冲击
- 触发条件：受击、护盾损失、贴身碰撞
- 强联动：`量子护盾核`、`等离子膜肺`、`护盾编织膜`
- 弱联动：`相位切断臂`
- 限制 / 代价：偏反打，爆发节奏受敌人行为影响

#### 四、资源特化器官

**12. 纳米复制腺**
- 主要流派：终局资源复制
- 输出 / 成长方向：资源
- 主要效果：在消耗较大段护盾后，对高价值矿物或稀有材料执行低频复制判定
- 触发条件：主动技能、加工行为、满盾消耗
- 强联动：`量子护盾核`、`纳米回充巢`、`棱镜演算脑`
- 弱联动：`采能步进足`、`护盾编织膜`
- 限制 / 代价：触发频率必须低，且需要明确材料白名单与成本

**13. 采能步进足**
- 主要流派：终局资源复制 / 护盾压制近战
- 输出 / 成长方向：资源 / 机动
- 主要效果：移动、跳跃或采掘时为周围环境充能，随后回收成少量护盾或采集效率加成
- 触发条件：移动、跳跃、采掘
- 强联动：`等离子膜肺`、`纳米复制腺`
- 弱联动：`光矛抛射腱`、`纳米修复网`
- 限制 / 代价：收益偏稳定积累，不提供瞬时大爆发

**14. 零损采样爪**
- 主要流派：终局资源复制
- 输出 / 成长方向：资源
- 主要效果：对极少量高价值方块或掉落执行无损采样，降低复制链的前置材料损耗
- 触发条件：采掘、拾取稀有材料、主动采样
- 强联动：`纳米复制腺`、`棱镜演算脑`
- 弱联动：`采能步进足`
- 限制 / 代价：对象白名单必须严格，且单次收益很低

### 推荐联动范式

#### 1. 护盾稳态链

`量子护盾核` + `等离子膜肺` + `纳米回充巢`

- 目标：把未来义体的基础护盾循环稳定下来
- 价值：让 T2 的强度来源清楚落在护盾而不是生命值

#### 2. 护盾压制链

`量子护盾核` + `护盾编织膜` + `纳米修复网` + `相位切断臂` + `偏折棱肩`

- 目标：把高护盾转成近战压制和反击威慑
- 价值：让近战方向有清晰的“先顶住，再反切”体验

#### 3. 过载狙杀链

`量子护盾核` + `过载稳相脊` + `矢量锁定眼` + `棱镜演算脑` + `光矛抛射腱`

- 目标：靠满盾窗口换一次远程锁定爆发
- 价值：明确区分于 T1 的工业连续输出风格

#### 4. 终局复制链

`量子护盾核` + `纳米回充巢` + `纳米修复网` + `采能步进足` + `零损采样爪` + `纳米复制腺`

- 目标：把多余护盾稳步转成稀有资源收益
- 价值：让 T2 的资源路线体现终局科技的高门槛高回报

### 落地思路

如果后面把这套计划落成 OEP / KubeJS，建议把复杂度放在“护盾区间”和“窗口消费”上：

- `conditions`：高护盾、满盾、受击、移动、锁定、采掘
- `grants`：基础护盾上限、被动回充、锁定辅助、资源白名单增益
- `events`：护盾回复、护盾损失、过载触发、纳米回充、锁定建立
- `executions`：相位重击、能量矛、偏折冲击、复制判定

推荐优先实现的效果类型：

- 高护盾区间增伤 / 穿透 / 冷却压缩
- 护盾损失后的反击或回充
- 锁定后的弹道修正与多段命中
- 高成本低频率的终局资源复制

### T2 的独立完成度

`Mekanism.T2` 在来源定位上应被视为终局未来义体，而不是 `T1` 的附属升级包。  
它的成立条件只有三件事：

- 玩家能理解这套来源的核心是护盾、过载与纳米，而不是基础工业循环
- 玩家能在近战压制、远程狙杀和终局复制之间做明确构筑选择
- 玩家能为高上限收益支付明显代价，例如掉盾、窗口期和高成本复制

因此 T2 应作为独立来源单独成立。  
它回答的是“未来义体如何把护盾资源转成终局战斗与成长收益”，不需要借助 T1 才能被理解。
