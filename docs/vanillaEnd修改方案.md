# 原版末影 / 潜影实际落地稿

## 本轮调整结论

末地不再保留“虚空折能攒满 -> 半量清仓 -> 短距爆发”的旧主核。末地应被写成**折跃维持链**：虚空折能是位相余量，通过位移、传送、末地结构和虚空击杀维持；核心开启持续门隙守卫窗口，按秒消耗折能，并强化折门拳峰、影喉囊和末影法术，而不是一次清空。

- 新增 `虚空导线`、`折跃锚`、`紫珀神经索`、`末影锚线` 四类非器官辅助件。
- 辅助件不是合成材料，而是增强特定器官的“虚空线路 / 折跃锚点 / 神经索 / 锚线”。
- `虚空守卫核心` 改为持续 `vanillaEnd_void_guard` 窗口，不再使用 `等级 = 消耗折能 / 5` 的旧公式。

## 一、来源与主场

- 来源身份：原版末地的基底地形和结构，加上 Cataclysm 的末地主线内容（`Ender Golem` / `Ender Guardian`），不把来源写成纯瞬移刺客，也不写成纯 Boss 套。
- 保持主场条件不变：维度 `minecraft:the_end`，末地群系，以及 `minecraft:end_city`、`minecraft:end_ship`、折跃门结构。
- 基础面板不变：现有 20 个器官的生命、护甲、护甲韧性、击退抗性、末影法抗、`max_mana`、`mana_regen`、`ender_spell_power`、`cooldown_reduction`、`cast_time_reduction` 等保留，不因这次收敛改动底数。
- 功能类特效收敛：每个器官只保留一个主要落点；删除设计稿里的多候选效果和当前 JSON 里的同模板复制。
- 本稿不再“暂缓 / 不纳入第一版”：20 个设计器官全部有唯一落点，避免特色内容缺失。

## 二、资源与窗口

只保留一个核心累计资源：

- `虚空折能`（解释为折返 / 门隙点），实现继续使用 `kubejs:vanillaEnd_resonance` + `kubejs:vanillaEnd_resonance_capacity`。
- 折返产源：移动、跳跃、位移、受击回避、空中命中、短距传送。
- 门隙产源：末地主场、折跃门、末地城 / 末地船结构、击杀潜影 / 末影系 / Cataclysm 末影傀儡 / 末影守卫、采掘末地石 / 紫珀 / 末地砖。
- 固定消耗端：`影喉囊`、`折门拳峰` 各消耗 12 点；`折跃锚` 在线时降至 10 点。
- 持续消耗端：`虚空守卫核心` 开启 `vanillaEnd_void_guard` 后按秒消耗 2 点折能。
- 衰减端：离开末地或门隙条件 20 秒后，虚空折能每 3 秒损失 1 点；避免在主世界无限囤积。
- 阈值转化：`末影肺叶`、`门缝冠脑`、`末界肩甲`、`门隙尾椎`只允许读取折能阈值，不新增第二个显式资源。

门隙窗口继续保留现有四种环境判定：

- `gate_online`：末地折跃门 / 末地传送门结构。
- `city_online`：`minecraft:end_city` / `minecraft:end_ship` 结构。
- `air_online`：`minecraft:small_end_islands` 群系。
- `home`：`minecraft:the_end`、末地群系、末地城 / 折跃门结构。

基础能力离开末地仍可用；门隙窗口只提供增幅、概率或窗口时长的额外收益，不让器官离场即废。

### 非器官辅助件（虚空线路 / 折跃锚点）

末地的辅助件是“虚空导线、折跃锚和神经索”，必须实际增强指定器官：

| 辅助件 | 增强对象 | 具体作用 |
|---|---|---|
| `虚空导线` `kubejs:void_conduit` | `折返脊炉`、`末门囊肺` | 折返脊炉位移/回避叠折能额外 +1；末门囊肺在门隙窗口内移动速度 +1，每 2 秒恢复 2 点法力 |
| `折跃锚` `kubejs:gate_anchor` | `折门拳峰`、`影喉囊` | 两个主动技能固定消耗由 12 点降至 10 点，且折门拳峰折跃距离 +2 格 |
| `紫珀神经索` `kubejs:purpur_nerve_cord` | `门缝冠脑`、`末影肺叶` | 门缝冠脑位移后末影法强化窗口 +1 秒；末影肺叶空间裂伤/漂浮触发概率提高 25% |
| `末影锚线` `kubejs:ender_tether` | `翼折肩环`、`末跃腿腱` | 翼折肩环滑翔转向修正 +15%；末跃腿腱高空窗口移动速度 +1，每次跳跃额外 +1 折能 |

这些辅助件进入 runtime 谓词，并由对应器官词条实际读取，不能只写进配方或任务。

## 四、新增核心器官

**虚空守卫核心**（原稿定位为 `门隙跃核`，改名为明确 Cataclysm 来源）

- 来源：解剖 Cataclysm 的 `末影守卫`（`cataclysm:ender_guardian`）和 `末影傀儡`（`cataclysm:ender_golem`）；材料锚定 `cataclysm:void_core`、`cataclysm:void_shard`、`cataclysm:void_eye` 等实际虚空系物品，具体掉落遵守现有 `organ_sources`。
- 物品 ID：建议新增 `kubejs:void_guard_core`。
- 主动技能：开启 `vanillaEnd_void_guard`，持续 8 秒，期间每秒消耗 2 点虚空折能。
- 窗口效果：玩家每 2 秒获得一次短距相位折跃，优先绕到最近带末地标记或门隙压制目标身后；命中后造成 3 点虚空裂伤，并在 5 秒内使 `末影肺叶`、`门缝冠脑` 和 `门隙尾椎` 各获得 +2 对应强度。
- 回收：窗口内每次折跃命中或击杀末地系目标返还 3 点虚空折能；没有目标时只获得短时移动和末影法稳定，不会半量清空折能。
- 表现：吸收 Cataclysm 的传送打击、虚空符文、虚空榴弹气质，但只做持续门隙守卫窗口，不复刻 Boss 连招。

## 五、Cataclysm 末影傀儡内容吸收

精确使用 Cataclysm 已有内容，不瞎猜招式：

- `Ender Golem`（末影傀儡）：以 Void Rune、地震 / 近战和末地城周边高压精英语义吸收。
- `Ender Guardian`（末影守卫）：以传送打击、火箭拳 / 上勾拳、区域攻击、Ender Guardian Bullet、Void Rune 等高压 Boss 语义吸收。
- `Void Howitzer`（虚空榴弹）只作为核心主动的空间爆发气质参考，不直接调用 Boss 完整招式。
- Cataclysm 的虚空祭坛、末影守卫 / 末影傀儡相关结构用于扩展门隙窗口和末地高压站场语义，不复制 Mod 的建筑系统。

## 六、原版末地内容吸收

原版末地不只是“末地维度”，必须保留以下识别点和结构语义：

- 基底地形：末地石空岛、末地高岛、浮岛边缘、高空平台、虚空与坠落风险。
- 结构内容：末地城、末地船、折跃门、末地传送门、末地水晶龙战平台。
- 生态内容：末影人、潜影贝、末影螨、紫颂植物、末影珍珠、潜影壳、鞘翅、龙息和末地资源。
- 方块语义：末地石、末地石砖、紫珀、紫珀柱、末地烛、末地砖、紫颂花 / 紫颂植物。
- 门隙窗口的 `city_online` / `gate_online` / `air_online` 只从末地城、末地船、折跃门结构和末地群系触发，不做人工标记。

## 七、联动与边界

- **折返底盘链**：`虚空导线` -> `虚空心室` + `折返脊炉` + `紫珀胸甲膜` + `门缝冠脑`。
- **空战追击链**：`末影锚线` -> `末跃腿腱` + `翼折肩环` + `折影臂束` + `末纹虹膜`。
- **末影法斗链**：`紫珀神经索` -> `龙息肝囊` + `末影肺叶` + `门缝冠脑` + `虚空守卫核心`。
- **末地城 / 门隙成长链**：`潜影脾囊` + `末石回流腺` + `末影疣肝` + `末尘脾膜` + `末门囊肺`。
- **Boss / 收尾链**：`折跃锚` -> `折门拳峰` + `末界肩甲` + `门隙尾椎` + `影喉囊` + `虚空守卫核心`。

复杂度边界：

- 不引入多资源互转，只用 `虚空折能` 一个计数，四类门隙窗口是环境条件而不是资源。
- 主动技能只保留 `影喉囊`、`折门拳峰`、`虚空守卫核心` 三个；`影喉囊` / `折门拳峰` 固定消耗，`虚空守卫核心` 持续消耗。
- 每个器官只承担“产 / 耗 / 转化 / 窗口”四类中的一类，避免沙漠和地狱体系里单器官叠 7 类字段的问题。
- 让 `虚空折能` 有明确出口：两个固定消耗技能和一个持续窗口是核心消费端，其余阈值器官只做短时窗口，不让储能变成只进不出的日志。

## 八、当前 JSON 修改点

- 新增 `void_guard_core`，技能开启 `vanillaEnd_void_guard` 窗口，不再使用“消耗一半 -> 等级 = 消耗折能 / 5”公式。
- 新增 `void_conduit`、`gate_anchor`、`purpur_nerve_cord`、`ender_tether` 四个辅助件，进入 runtime 谓词，并由 `折返脊炉`、`末门囊肺`、`折门拳峰`、`影喉囊`、`门缝冠脑`、`末影肺叶`、`翼折肩环`、`末跃腿腱` 等词条实际读取。
- `vanillaEnd_runtime.js` 增加折能离场衰减和辅助件在线判定；`vanillaEnd_organs.js` / tags 注册 `void_guard_core`。

## 九、数值与可实现性边界

- 虚空折能默认上限维持 50 点。
- 固定主动技能 12 点，`折跃锚` 在线时 10 点；`虚空守卫核心` 启动需 24 点，之后每秒消耗 2 点。
- 离开末地 / 门隙条件 20 秒后折能每 3 秒衰减 1 点。
- 不使用自定义空间裂伤实体；空间裂伤、漂浮、位移和折跃效果使用现有 OEP 效果、末影法术或 Cataclysm 虚空系表现。
- 不新增独立维度、自定义门隙方块或 Boss 连段状态机。
