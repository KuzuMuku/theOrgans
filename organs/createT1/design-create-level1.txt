### 核心目标

这套计划书对应 `机械动力.安山` 来源的 T1 器官组，是整套机械义体路线的起点。  
它服务的不是“复杂工业模拟”，而是一个很清楚的构筑问题：

- 来源：`Create 安山阶段` 的粗机械、飞轮、活塞、齿轮和低阶加工。
- 加成主题：`蒸汽朋克`，但主题不能盖过来源身份。
- 主要流派：`蓄压爆发近战` 与 `机械采掘资源`。
- 核心资源：只有一条 `当前应力 / 应力上限` 读数。

T1 的任务不是把系统做复杂，而是把“能蓄压、能放空、能转成战斗或采掘收益”这条基础路线跑通。

---

### 核心思路

这套系统的体验应当接近 Create 本体的低阶机械：

- 平时靠水车、风车、动作惯性把飞轮慢慢带起来。
- 心脏负责把零散输入存成可消费的应力。
- 输出器官负责把应力放空，形成爆发或持续负载。
- 资源器官负责把应力换成更高采掘效率与粗加工收益。

因此 T1 的设计边界也很明确：

- 不拆成多条并行资源。
- 不做可编程序列。
- 不让单个器官同时承担输出、防御、位移、增产四份职责。
- 复杂感只来自“蓄压链”和“放压链”的组合。

---

### 来源定位与流派边界

来源：`机械动力.安山`

主要流派：

- `蓄压爆发近战`
- `持续负载近战`
- `机械采掘加工`

输出 / 成长方向：

- 近战：重击、击退、冲锋、持续切割
- 资源：采矿、粉碎、副产物提升

不承担的方向：

- 不主打法术
- 不主打精密节拍
- 不主打自动化后勤

### 当前建议保留的 10 个核心件

#### 一、驱动器官

**1. 安山飞轮心脏**
- 主要流派：全部安山流派共用核心
- 输出 / 成长方向：蓄压底盘
- 主要效果：提供基础应力上限，并存储其他器官输入的机械负载
- 触发条件：常驻
- 强联动：`微型水车`、`微型风车`、`增压传动轴`
- 弱联动：全部应力消耗器官
- 限制 / 代价：自身不直接提供明显输出

**2. 微型水车**
- 主要流派：稳定蓄压
- 输出 / 成长方向：资源 / 通用
- 主要效果：稳定、缓慢地产出应力
- 触发条件：常驻或环境驱动
- 强联动：`安山飞轮心脏`
- 弱联动：全部放压器官
- 限制 / 代价：回充慢，爆发前需要预热

**3. 微型风车**
- 主要流派：机动蓄压
- 输出 / 成长方向：通用
- 主要效果：移动时按速度回充应力
- 触发条件：移动、冲刺、位移
- 强联动：`安山飞轮心脏`
- 弱联动：`弹射撞角`
- 限制 / 代价：站桩时收益低

**4. 增压传动轴**
- 主要流派：蓄压爆发 / 采掘加工
- 输出 / 成长方向：通用增幅
- 主要效果：提高应力上限，并在攻击、挖掘时继续积蓄应力
- 触发条件：攻击、挖掘
- 强联动：`安山飞轮心脏`
- 弱联动：全部高耗应力器官
- 限制 / 代价：受击后蓄压节奏容易中断

#### 二、近战特化器官

**5. 活塞冲拳**
- 主要流派：蓄压爆发近战
- 输出 / 成长方向：近战
- 主要效果：主动抽空当前全部应力，打出高伤害重拳与强击退
- 触发条件：主动技能 / 攻击释放
- 强联动：`安山飞轮心脏`
- 弱联动：`增压传动轴`
- 限制 / 代价：一击后会清空储备

**6. 动力锤击**
- 主要流派：反击近战
- 输出 / 成长方向：近战 / 生存
- 主要效果：受击时自动消耗一段应力反砸周围目标
- 触发条件：受击
- 强联动：`安山飞轮心脏`
- 弱联动：`微型水车`
- 限制 / 代价：低应力时收益明显变差

**7. 弹射撞角**
- 主要流派：突入近战
- 输出 / 成长方向：机动 / 近战
- 主要效果：消耗应力进行短距离冲锋并撞飞首个目标
- 触发条件：主动技能
- 强联动：`微型风车`
- 弱联动：`活塞冲拳`
- 限制 / 代价：需要预留应力，失手时很亏

**8. 传动链锯**
- 主要流派：持续负载近战
- 输出 / 成长方向：近战
- 主要效果：持续消耗应力维持高速切割，对贴身目标造成连段伤害
- 触发条件：主动开启 / 持续运转
- 强联动：`安山飞轮心脏`
- 弱联动：`增压传动轴`
- 限制 / 代价：烧应力快，续航强依赖蓄压链

#### 三、资源特化器官

**9. 应力镐**
- 主要流派：机械采掘
- 输出 / 成长方向：资源
- 主要效果：主动消耗大量应力，快速粉碎前方短锥范围矿块
- 触发条件：主动技能 / 挖掘
- 强联动：`安山飞轮心脏`
- 弱联动：`增压传动轴`
- 限制 / 代价：会明显抽低应力，并应保留工具损耗或冷却代价

**10. 粉碎齿轮**
- 主要流派：粗加工增产
- 输出 / 成长方向：资源
- 主要效果：消耗应力处理原矿，提高金属收益并伴随石渣副产物
- 触发条件：加工行为 / 主动使用
- 强联动：`应力镐`
- 弱联动：`微型水车`
- 限制 / 代价：应有噪音、副产物或速率限制，不能变成无条件全局增产

### 推荐联动范式

#### 1. 蓄压链

`安山飞轮心脏` + `微型水车` + `微型风车` + `增压传动轴`

- 目标：稳定攒满飞轮
- 价值：让安山体系先有“能转起来”的基本盘

#### 2. 超频爆发链

`安山飞轮心脏` + `活塞冲拳`

- 目标：用满应力换一次明确爆发
- 价值：一眼就能理解“蓄压是为了什么”

#### 3. 持续负载链

`安山飞轮心脏` + `传动链锯`

- 目标：把已储存应力稳定换成持续近战输出
- 价值：和一次放空型器官形成玩法分流

#### 4. 采掘加工链

`应力镐` + `粉碎齿轮`

- 目标：形成“前端采掘 + 后端粗加工”的资源路线
- 价值：让机械来源不只服务战斗

### 落地思路

如果后面把这套计划落成 OEP / KubeJS，建议遵守以下实现边界：

- `conditions` 负责环境、移动、挖掘、受击等触发门槛
- `grants` 负责基础应力上限、被动属性与静态采掘加成
- `events` 负责蓄压、消耗、计层，不直接塞视觉效果
- `executions` 负责重拳、冲锋、切割、采矿等可见结果

推荐优先实现的事件类型：

- `move`
- `attack`
- `attacked`
- `mine`
- `use_item` / 主动技能事件

### T1 对 T2 的明确交接

T1 已经足够承担“安山起步”职责，因此这里只做小幅校正，不推翻原方向。  
它交给 T2 的升级重点只有三件事：

- 更高的应力上限
- 更明确的高压增幅
- 更完整的采掘加工链

也就是说，T1 负责回答“怎么把飞轮转起来”，T2 才去回答“高压以后怎么更值地花出去”。
