# 器官流派扩展方案

本文基于 [mod玩法与任务线设计.md](/home/kuzuanpa/projects/1.20.1/theOrgans/mod玩法与任务线设计.md:1) 与 [器官设计核心哲学.md](/home/kuzuanpa/projects/1.20.1/theOrgans/器官设计核心哲学.md:1) 重整现有器官流派表，目标是把“有独特内容的 mod”尽量纳入器官体系，同时避免来源和主题重复。

## 一、先改表的规则

### 1. 什么能当“来源”

只有满足下列至少两条的 mod/体系，才建议进入“来源”列：

- 自己提供了稳定的材料、敌人、结构、维度或生产链。
- 玩家一眼能理解“这套器官是从什么东西身上/体系里拆出来的”。
- 不依赖另一个大体系作为解释前提。
- 能自然映射到近战 / 弓箭 / 法术 / 资源四类输出之一。

### 2. 什么只能当“加成主题”

下列内容不要占用“来源”：

- 更像施法框架、上层职业、后期增幅器的 mod。
- 本身没有明确“生态/阵营/工业实体来源”，更偏玩法组织方式。
- 与已有来源高度重叠，但能提供一套独特强化逻辑。

因此：

- `Iron's Spells 'n Spellbooks` 继续放在“加成主题”。
- `Ars Nouveau` 也建议放在“加成主题”。
- `Botania` 更适合作为“来源”，因为它提供的是花卉工艺、法力工艺与自然装置这一整套可辨识底层体系；它再去承接 `铁魔法.自然` 或其他主题增幅，而不是自己作为主题名出现。

### 3. 什么暂时不进主表

有些 mod 很有内容，但和当前“三输出 + 资源”框架不匹配，强塞会让表失真：

- `TACZ`
  - 本质需要单独的“火器输出”列；硬塞进弓箭会污染弓系设计。
- `Tom's Storage` / `Sophisticated` / `AE2`
  - 这些更像后勤系统，应做资源器官的后期联动，不适合作为来源。
- `Waystones` / 建筑类 / 地图类 / 地牢生成增强类
  - 适合做任务奖励、结构掉落、器官出处补充，不适合单独成系。

## 四、Ars Nouveau 并入铁魔法的处理

你提出的方向更合理：既然表格这一层表现的是“加成主题”，那么不应该让玩家看到两套并列的魔法 school。`Ars Nouveau` 更适合作为 `Iron's Spells` 几个主题的实现风格补充，而不是再独立列出一套主题名。

建议并入方式如下：

- `Ars Nouveau` 的位移/换位/跃迁能力并入 `铁魔法.末影`
  - 让空间法术统一归到末影主题。
- `Ars Nouveau` 的使魔、跟班、协战能力并入 `铁魔法.召唤`
  - 区别只体现在器官词条风格上，不再额外开新主题。
- `Ars Nouveau` 的法阵、区域控制、长期布置并入 `铁魔法.圣` 与 `铁魔法.幽匿`
  - 正向驻场、保护、净化归 `圣`
  - 黑暗、压制、场域妨害归 `幽匿`
- `Ars Nouveau` 的自然协同与植物性法术并入 `铁魔法.自然`
  - 保留自然法术感，但不形成平行魔法体系。
- `Ars Nouveau` 的弹道编辑、预存法术、法术缓存、回蓝续航
  - 不再作为单独主题列出。
  - 这些更适合写进具体器官词条，作为主题内部的机制差异。

这样处理后，表层只保留一套魔法主题名，玩家认知会更统一：

- `Iron's Spells` 负责主题命名
- `Ars Nouveau` 负责给这些主题提供更工程化、可编排的器官机制

`Botania` 现在不作为加成主题，而改为来源。它负责提供“花卉工艺 / 法力工艺 / 自然装置”这类底层身份，再去挂接 `铁魔法.自然`。这样它既不会和自然魔法主题重名，也不会丢掉自身的独特来源价值。

`原版异常.蘑菇岛` 已并入 `原版群系.孢菌洞穴`，不再作为独立来源保留。它的真菌、孢子、菌丝、异常共生与稳态生存意象，统一转入繁茂洞穴体系中。

`Deeper and Darker` 不再单列来源，直接并入 `原版结构.幽匿`。原因是它在整合包叙事里更像“幽匿生态的深层延展”，不是一个与幽匿平行的新身份。

`Cataclysm` 也不再单列来源。它更适合作为多个原版/维度来源的毕业 Boss 层：

- 下界手并入 `原版结构.地狱`
- 利维坦并入 `原版结构.海洋`
- 其他灾厄遗迹并入对应群系/维度的毕业器官掉落池

这样能保留 Cataclysm 的强度地位，但不会破坏“来源必须是稳定生态/体系”的原则。

## 六、当前不建议单独成系的 mod

这些 mod 有价值，但不建议现在直接塞进来源表：

- `AE2`
  - 更适合作为资源器官的后期阈值联动，例如“资源器官 4 件后掉落自动入网”。
- `Create Central Kitchen` / `Farmer's Delight`
  - 适合作为资源器官掉落与食物增益联动，不必单独做器官大系。
- `Bosses of Mass Destruction`
  - 更适合给现有来源补 Boss 掉落器官，而不是独立来源。
- `Cataclysm`
  - 更适合作为多个来源的毕业 Boss 池，而不是独立来源；它的器官设计应分配回海洋、地狱、沙漠、末地等对应来源。
- `TACZ`
  - 等你愿意把表从“近战/弓箭/法术/资源”扩成“近战/弓箭/火器/法术/资源”后，再单独开系最合理。

## 七、最终落地建议

如果你准备把这份方案真的填进当前表格，我建议结构改成：

1. `来源总表`
2. `加成主题总表`
3. `来源 x 输出方式` 的器官模板表
4. `主题 x 元素点` 的 Synergia 附着表

不要再把“来源表”和“加成主题表”混在同一列高里靠人工理解，否则后面器官一多会很难维护。
