# Create T2（机械动力.黄铜）稳定驱动实现稿

## 0. 总纲

Create T2 的核心不是“高压爆发”，而是“稳定驱动的机械系统”。玩家要回答的问题是：

- 我的黄铜机械线是否能在高应力负载下持续运行？
- 我把应力导给谁、润滑给谁、让哪一条产线维持精密输出？
- 我是选择重装突破、稳定近战，还是长期采掘加工？

本稿保留当前 `kubejs:torque / kubejs:torque_capacity` 作为唯一资源条，但它不再是清空式爆发资源。应力在这里更像“负载等级”：低负载是待机，中负载是稳定运行，高负载是满载但需要散热和润滑。

Create T2 不做的方向：

- 不做法术增幅、魔力资源、施法倍率。
- 不做“清空应力 -> 超载大爆发”的核心主动。
- 不做需要维护小型自动机的多阶段流程。
- 不把 Create New Age / Create Enchantment Industry 变成第二个资源体系。

---

## 一、来源与流派

```text
来源：机械动力.黄铜
加成主题：蒸汽朋克 / 精巧匠艺
主要流派：稳定近战武装 / 精密加工 / 自动循环
输出 / 成长方向：近战、采掘、加工收益
```

Create T2 的玩法节奏是“越稳定、越赚”。它奖励玩家先搭好压力、飞轮、离合、润滑、节拍的持续运转链，再在这个稳定底盘上挂主动武装，而不是靠一次性清掉资源来换伤害。

典型构筑：

- 稳定近战线：恒压心室 -> 锻炉肺 -> 打桩拳，靠高负载下的稳定破甲输出。
- 精密加工线：飞轮囊 -> 节拍器 -> 配压膜 -> 钻机，靠持续采掘和加工返利成长。
- 自动循环线：离合脊 -> 润滑回流腺 -> 恒动星核，把空耗降到最低。

---

## 二、核心资源与运行档位

唯一资源条：

```text
kubejs:torque：当前应力
kubejs:torque_capacity：应力上限
```

短时 runtime 状态不是第二条资源：

- `brass_running_online`：黄铜系统在线。
- `brass_cruise_online`：稳定运行协议。
- `brass_rhythm`：连续动作节拍。
- `brass_load_high`：高负载窗口。
- `brass_idle_online`：低负载待机。

运行档位建议：

| 档位 | 应力条件 | 玩家感受 |
|---|---|---|
| 待机 | 低应力 | 系统能转，但增益很小 |
| 巡航 | 中高应力 | 系统稳定，加工和近战获得稳定增幅 |
| 满载 | 高应力 | 系统收益高，但必须靠润滑/冷却抑制空耗 |

Create T2 的主动技能不能破坏这个分层。核心主动应该让玩家进入“满载巡航”，而不是清空应力进入短暂超载。

---

## 三、非器官装配件

机械动力来源不一定要把每一个组件都写成生物器官。设计方案里允许并鼓励出现“电线、管道、轴承、滑轨”这类非器官装配件，它们可以参与手术配方、启动判定、固定装配效果或后续独立部件槽。

| 装配件 | 定位 | 设计作用 |
|---|---|---|
| `黄铜应力导线` | 线路 | 把应力分配给多个耗能部件，降低单点负载 |
| `黄铜冷却回流管` | 管道 | 处理高压空耗，让满载巡航不会快速停机 |
| `配重轴承` | 转动件 | 稳定飞轮输出，增强节拍与加工稳定 |
| `黄铜离合滑轨` | 传动件 | 让主动重击和钻机切换更平滑 |
| `经验蚀刻线` | 精加工件 | 用 CEI 经验流体做维护，不产生魔力 |

这些装配件不占“生物器官”的语义，它们是机械来源本体的一部分。

## 四、器官/机械部件落地清单

保留现有机械部件和新增项，整个来源共 11 个可落地组件。表中既有器官，也有机械部件；每个组件只承担一个主职责。

| 组件 | 类别 | 主要效果 | 触发 | 限制 / 代价 |
|---|---|---|---|---|
| 黄铜增压心室 `brass_pressure_ventricle` | 器官 | 提供应力上限与稳定负载底盘 | 常驻；黄铜四件共振时提高承载 | 自身不主动消耗应力，也不直接增伤 |
| 配重飞轮囊 `weighted_flywheel_sac` | 器官/机械 | 持续积累稳定应力，在满载时把溢出转化为节拍层 +1 | tick / 移动 / 加工链输入 | 站桩不产压；满载溢出只做短时稳定，不做无限叠层 |
| 黄铜离合脊 `brass_clutch_spine` | 器官/机械 | 高压时持续件空耗 -15%，主动切换稳定巡航 | 高应力区间；主动释放 | 偏续航，不提高单次爆发伤害 |
| 节拍校准耳蜗 `tempo_calibration_cochlea` | 器官 | 连续命中/挖掘 3 次后，5 秒内命中率 +10%、加工产出 +1 | `deal_damage` / `mine` 短窗口 | 断档即清空，不能远程挂机 |
| 增压锻炉肺 `overpressure_forge_lung` | 器官 | 满载近战命中附加破甲，并使下一次近战伤害 +4 | 满载窗口 + `deal_damage` | 低负载无增益；不额外触发范围伤害 |
| 润滑回流腺 `lubrication_reflux_gland` | 器官/机械 | 泄压或持续运转时返还 5 点应力 | `spend` / 泄压 / 持续运转 | 只做续航，不提高单次峰值 |
| 配压黄铜膜 `pressure_balance_brass_membrane` | 机械 | 满载巡航时使其他黄铜件加工产出 +1、近战伤害 +2 | 满载窗口 | 低压几乎无收益，必须先维持稳定负载 |
| 黄铜打桩拳 `brass_pile_driver` | 器官 | 消耗 32 应力打出重击，基础伤害 12；满载时伤害 +4、命中率 +10% | 主动技能 | 消耗 32 应力，冷却 90 秒；不是清空式技能 |
| 棘轮破城肩 `ratchet_breach_shoulder` | 机械 | 移动/受击/命中蓄势冲势，主动肩撞打乱目标 | 主动技能 + 动作蓄势 | 需要蓄势，不独立清空应力 |
| 螺旋掘进钻 `spiral_tunnel_drill` | 机械 | 持续消耗应力定向掘进 8 格；巡航档额外获得 1 个加工副产物 | 主动技能 / 挖掘 | 消耗 24 应力，冷却 120 秒 |
| 黄铜恒动星核 `brass_constancy_star_core` | 核心 | 主动进入满载巡航窗口，8 秒内近战伤害 +4、加工产出 +1 | 主动技能 | 见下方核心说明 |

## 五、新增核心器官：黄铜恒动星核

`brass_constancy_star_core`

- 来源：黄铜机体、Create 飞轮、精密机构，加上 Create New Age 的电工材料作为扩容接口。
- 主要流派：全部黄铜流派共同使用的稳定运行落点。
- 主要效果：主动开启 `brass_cruise_online`，持续时间 10 秒。窗口内应力空耗 -20%，近战破甲伤害 +4，采掘/加工产出 +1，且不要求清空当前应力。
- 触发条件：当前应力不低于 24，且黄铜体系已在线。
- 限制 / 代价：开启后应力不会自动上涨，只维持当前负载；结束后进入短暂惰性待机，不能连续开启。
- 联动对象：强联动 `增压心室`、`飞轮囊`、`配压膜`；弱联动 `打桩拳`、`钻机`、`润滑回流腺`。

这个核心不是“消耗一半去爆发”，而是“锁住稳定的高负载状态去做持续输出”。

---

## 六、联动链

1. 稳定负载链

```text
增压心室 -> 配重飞轮囊 -> 离合脊 -> 润滑回流腺
```

心室提供上限，飞轮稳定产出，离合降低空耗，润滑把空转损耗回收回来。

2. 精密加工链

```text
节拍校准耳蜗 -> 配压黄铜膜 -> 螺旋掘进钻 -> 恒动星核
```

节拍管连续动作，配压膜管满载效率，钻机把稳定应力转成采掘收益，恒动星核维持这个满载窗口。

3. 稳定重击链

```text
增压心室 -> 增压锻炉肺 -> 黄铜打桩拳 -> 棘轮破城肩
```

锻炉肺负责稳定破甲，打桩拳负责重击，破城肩负责蓄势突入，核心不是清空爆发而是稳定推动整条链。

---

## 七、实现要点

- 保留 `kubejs:torque` 与 `kubejs:torque_capacity` 作为唯一资源点。
- 删除旧的 `createT2_has_mana`、`createT2_has_spell`、法术/魔力链路。
- 新增非器官装配件时，可以先作为手术配方、固定 assembly 效果或启动判定；不要求它们全部挤进器官 JSON。
- 主动技能落点：`brass_pile_driver`、`spiral_tunnel_drill`、`brass_constancy_star_core`、`ratchet_breach_shoulder`。
- 不要让任何一个组件同时承担“攻击回应力 + 回血 + 加抗性 + 加工返利”的多职责模板。

---

## 八、验收标准

- 玩家能说清：这套体系的强度来自“稳定负载”，而不是“一次清空应力”。
- 不出现“清空全部应力 -> 短暂超载大爆发”的核心主动。
- 文档和词条里同时包含器官与机械组件，如导线、管道、轴承、滑轨。
- 每件可落地组件只保留一个主效果。
- Create T2 不再承担法术、魔力、附魔施法来源。
