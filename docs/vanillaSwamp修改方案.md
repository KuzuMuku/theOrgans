# 原版沼泽实现稿（vanillaSwamp）

## 一、文档定位与取舍标准

本文是 [design-vanilla-swamp.txt](/home/kuzuanpa/projects/1.20.1/theOrgans/organs/vanillaSwamp/design-vanilla-swamp.txt:1) 的下游实现稿，对标 `vanillaShulk实现方案.md` 的取舍强度。上游概念稿回答“沼泽是什么”：腐水、淤泥、苔藓、毒囊、史莱姆胶膜、巫术草药与潮腐湿气；本文回答每个器官最后装什么、触发什么事件、消耗什么资源，并把 `Ice and Fire` 的九头蛇作为本来源的中后期生态与猎杀层写进同一张施工图。

保留：

- 来源与主场：原版 `swamp` / `mangrove_swamp`、女巫小屋、雨天、涉水、泥地与潮湿环境判定不变。
- 基础面板：现有器官 JSON 的生命、护甲、韧性、移动速度、法力、自然法强、冷却缩减等基础属性不改。
- 功能宽度：沿用当前已经落地的 10 个常规器官，不砍掉法力件、资源件或主动件。
- 视觉主题：睡莲、泥浆、腐木、蘑菇、湿苔、史莱姆、青蛙、毒雾、女巫小屋与九头蛇毒息。

收敛：

- 核心状态只保留 `腐毒浓度` 与 `沼泽标记`，但 `腐毒浓度` 不再是“攒满后释放”的能量池，而是需要维持和转移的**腐殖接种量**。
- `胶膜活性`、`沼泽回响`、`腐毒窗口` 收敛为现有 runtime 窗口与关联层，不另开计数器。
- 每个器官只保留一个主生态位。删除“同一个器官同时做回血、回蓝、法强、减速、搜刮”的多候选写法。
- 补入 `泥脉导管`、`腐生菌丝`、`沼气囊`、`腐根泵` 四类自然辅助件，让腐毒能在目标和目标之间转移，而不是只从玩家身体里进出。
- 明确消耗端：毒囊花喉消耗 12 腐毒，黏液回蓝脾的湿地额外补给消耗 2 腐毒，九头腐核按持续时间消耗并回收标记目标。

新增一个核心器官：

`九头腐核`：来自解剖 `iceandfire:hydra`，连接原版沼泽毒系、自然法术与九头蛇再生/毒息语义，作为整套体系的**腐溃维持核心**，不再做成半量清仓的毒息爆发。

## 二、来源与主场

来源定位是：

```text
原版群系.沼泽/红树林沼泽 + Ice and Fire.九头蛇
```

`Ice and Fire` 不单独成为新来源。九头蛇原生于沼泽与红树林，其洞穴、毒牙、心脏和毒息作为本来源的高阶猎杀层与材料层；原版女巫、史莱姆、青蛙和湿地生态作为前期来源。这样才能保持“原版生态 + 来源稳定”的身份，不把沼泽变成“毒系模组合集”。

### 主场条件

保持现有 `vanillaSwamp_runtime.js` 的判定：

- 主世界（`minecraft:overworld`）。
- 群系关键字包含 `swamp` / `mangrove`。
- 附近存在 `minecraft:swamp_hut`，沿用现有 8 chunk 搜索半径。

落地时只做一处可选扩展：如果运行时注册了 `iceandfire:hydra_cave`，把它加入结构判定表；若当前 Ice and Fire 版本仍只通过 `WorldGenHydraCave` 生成、不注册该结构资源，则自动跳过，不因缺资源而阻塞。九头蛇洞穴仍主要由玩家主动搜图与猎杀进入，不把它变成无门槛的主场条件。

## 三、核心资源与状态

### 1. 腐毒浓度

保留现有 `kubejs:vanillaSwamp_resonance`，展示名统一叫“腐毒浓度”（现有英文 `Mire Venom` 可保留）。它代表由污泥、毒素、自然法伤、湿地活动与九头蛇毒液共同维持的**腐殖接种量**，不是蓄能池。

- 上限：`淤泥毒心 +50`，`腐苔滤肝 +8`，`九头腐核 +25`。
- 最低可用阈值：`vanillaSwamp_resource_online` 保留“至少 8 点”的约定。
- 生产端：自然法术施法/命中、近战命中、受击、移动、挖掘、击杀与沼泽生物回收。
- 转移端：`泥脉导管` 在带标记目标死亡或中毒加深时，把腐毒传给附近目标；`腐生菌丝` 从尸体和湿地植物回收腐毒。
- 转化端：施法回蓝、受击恢复、湿地额外补给。
- 消耗端：毒囊花喉主动技能 12 点；黏液回蓝脾湿地额外 roll 2 点；九头腐核按持续时间和标记目标数量消耗。
- 衰减端：离开湿地主场且不维持感染时，每 3 秒损失 1 点腐毒。沼泽玩的是“感染是否还在扩散”，不是“攒满后清仓”。

### 2. 沼泽标记

保留现有 `mark:kubejs:vanillaSwamp_mark`，展示名“沼泽标记”。它只表示目标已被黏液感知到，不承担经济资源功能。

- 上标记：史莱姆牵丝臂在胶膜活性窗口近战命中。
- 吃标记：毒囊花喉的近身毒雾优先覆盖带标记目标；九头腐核在腐溃窗口内对带标记目标持续扩散，并在其死亡时返还腐毒。

### 3. 三类窗口

- `胶膜活性`：`swamp` / `mangrove` 群系。
- `沼泽回响`：`swamp` / `mangrove` 群系或 `minecraft:swamp_hut` 结构。
- `腐毒窗口`：`minecraft:swamp_hut` 结构或 `iceandfire:hydra_cave` 结构。

这些窗口由现有 runtime predicate 计算，不新增第二、第三套可积累资源。

### 非器官辅助件

沼泽的自然辅助件不是“充能导线”，而是负责把腐毒从玩家身上传到敌人、尸体和泥地之间：

| 辅助件 | 定位 | 设计作用 |
|---|---|---|
| `泥脉导管` | 感染管线 | 让带沼泽标记的目标死亡或中毒时，把部分腐毒转移给附近目标，形成连锁感染 |
| `腐生菌丝` | 腐殖回收 | 把尸体、击杀和湿地植物转化为腐毒，但不直接给玩家回蓝 |
| `沼气囊` | 范围发酵 | 消耗 3 点腐毒，在 5 格范围施放 4 秒浊雾，使敌人中毒 2 秒、缓慢 2 秒 |
| `腐根泵` | 衰减控制 | 控制腐毒在普通环境的自然衰减，避免挂机无限发酵 |

这些辅助件让沼泽从“攒毒、喷毒、再攒毒”变成“上毒、转移、收割”。玩家不只需要制造腐毒，还需要把腐毒保持在正确的目标身上。

## 六、新增核心器官：九头腐核

- 物品 ID：`kubejs:hydra_venom_core`
- 中文名：九头腐核
- 来源：解剖 `iceandfire:hydra`，加入现有 `organ_source_iceandfire_hydra` 的 chest 槽位；`iceandfire:hydra_heart` 与 `iceandfire:hydra_fang` 进入手术材料链。
- 面板：`max_health +2`、`nature_spell_power +2`、腐毒上限 +25、`organsynergia:grass_affinity +4`。
- 定位：整套沼泽体系的腐溃维持核心，不是普通治疗件，也不是半量清仓毒息。
- 技能：ID `kubejs:hydra_venom_core`，`castEvent` 使用 `hydra_venom_core_cast`，冷却 200 tick。
- 释放流程：
  1. 当前腐毒浓度低于 20 时不生效。
  2. 开启 `vanillaSwamp_rotting_window`，持续 6 秒，期间每秒消耗 2 点腐毒。
  3. 窗口内对周围带 `vanillaSwamp_mark` 的目标持续施加中毒与缓慢，并由 `泥脉导管` 把目标死亡时未耗尽的中毒状态转移给附近敌人。
  4. 每个被窗口击杀的带标记目标返还 5 点腐毒，形成“收割尸体，继续感染”的循环。
  5. 每存在一个带沼泽标记目标，腐溃窗口传播范围 +1 格，上限 +5 格；不另做蛇头计数或半量等级公式。

`poison_breath` 只作为视觉/落地提示，不再承担“半量消耗 -> 毒息等级”的统一核心模板。九头蛇原生“断头再生、火封断口”仍由 Ice and Fire 自身机制负责；`hydra_heart` 的快捷栏受伤再生也保留原生行为，不把三者塞进同一个主动技能。

## 七、负面抑制与综合增强

### 负面抑制

- 自毒与沼泽环境不白吃：`腐苔滤肝` 在沼泽回响窗口自然法抗 +1、法力恢复 +1；`黏膜护壳` 与 `蛙蹼潜行腿` 把涉水、泥地、黏液地形造成的减速反制为移动速度 +1、击退抗性 +2。
- 持久战损耗有回收：`泥潭蓄腐囊` 把受击/命中转成短治疗与再生，`淤泥毒心` 提供湿地韧性底盘。
- 不做假负面：不新增致盲、反胃、勒死、中毒自身惩罚等流程；沼泽的“脏”由敌人身上的毒、缓慢、标记和黏液承担。

### 综合增强

- 自然法术：`孢浆沼肺` 给自然法强与施法时间缩减；`巫沼冠脑` 给冷却缩减与施法移速；`腐苔滤肝` 给法力续航。
- 生存：`淤泥毒心`、`黏膜护壳`、`泥潭蓄腐囊` 给出生命、护甲、韧性与受击恢复。
- 战斗：`史莱姆牵丝臂` 给近战挂毒与标记，`毒囊花喉` 给固定消耗毒雾，`九头腐核` 给持续腐溃窗口与标记回收。
- 资源：`黏液回蓝脾` 给湿地材料回收，九头蛇洞穴给高阶材料与猎杀成长。

### Synergia 元素点

现有 10 件全部使用 `organsynergia:grass_affinity`：

- 淤泥毒心 3、腐苔滤肝 4、泥潭蓄腐囊 2、黏膜护壳 2、史莱姆牵丝臂 3、毒囊花喉 2、蛙蹼潜行腿 1、孢浆沼肺 6、黏液回蓝脾 2、巫沼冠脑 4。
- 原有合计 29 点；新增九头腐核 +4 后为 33 点。

不混入毒、腐化、黑暗或火系元素点。九头蛇的战斗特性和火封再生属于 Ice and Fire 原生规则，不做成沼泽器官的法术元素来源。

## 八、联动链

### 1. 腐毒消耗链

```text
淤泥毒心 -> 泥潭蓄腐囊 -> 史莱姆牵丝臂 -> 孢浆沼肺 -> 腐苔滤肝 -> 毒囊花喉 / 九头腐核
```

心给容量，蓄腐囊与牵丝臂把战斗时间转成腐毒，沼肺与滤肝把施法转成腐毒和法力，最后由花喉或九头腐核把储量花出去。

### 2. 黏液锁人链

```text
黏膜护壳 + 史莱姆牵丝臂 + 蛙蹼潜行腿 + 毒囊花喉
```

腿负责湿地追击，护壳负责站住，牵丝臂负责上沼泽标记与毒，花喉负责把标记目标拖进毒雾和缓慢中。

### 3. 沼泽自然法链

```text
腐苔滤肝 -> 孢浆沼肺 -> 巫沼冠脑 -> 九头腐核
```

滤肝给蓝量和施法产腐毒，沼肺给自然法强与命中产腐毒，冠脑压缩施法节奏，九头腐核开启持续腐溃窗口并回收标记目标。

### 4. 湿地主场探索链

```text
淤泥毒心 + 黏膜护壳 + 蛙蹼潜行腿 + 黏液回蓝脾
```

这套链负责长期待在沼泽/红树林：湿地主场生存、机动、采集与资源回收完整成线。

### 5. 九头蛇猎杀链

```text
毒囊花喉 / 孢浆沼肺 -> 九头蛇洞穴 -> hydra_heart / hydra_fang -> 九头腐核
```

九头蛇原生火封再生与断头机制是战斗攻略，不写成器官数值；沼泽器官负责给你进入湿地猎杀时的毒系和自然法节奏。跨来源弱联动只允许“火法术让 Hydra 原生再生失效”这种现有模组规则，不让火系成为沼泽器官的强度来源。

## 十、数值与可实现性边界

- 腐毒默认上限控制：50 + 8 + 25；生产 +1 到 +2，固定消耗 2 / 12，腐溃窗口按每秒 2 点持续消耗。
- 主动技能冷却 200 tick；腐溃窗口持续 6 秒，结算只读 counter、mark 和短窗口，不做帧级流水线。
- 全部使用现有 `attacked`、`deal_damage`、`mine`、`kill`、`move`、`spell_cast`、`spell_hit`、`cooldown_added`、mark 和短窗口，不新增小型状态机。
- 不新增“蛇头计数”、“脱水条”、“毒层翻倍链”或“可控多段吐息”。多头由标记目标传播范围与九头蛇原生机制表达。
- 不做纯远程巫师，也不做纯坦克；核心闭环仍然依赖贴身、湿地、自然法伤与黏液锁人。
- 不把 Ice and Fire 原生 `hydra_arrow`、`hydra_heart`、断头再生、火封断口重写为新器官；特色内容靠真实实体、战利品、结构和材料链保留。

## 十一、与对照分析的反例规避

- 不重复沙漠/地狱“同源内部 `mine/kill` + 同一 loot 表”的模板：`黏液回蓝脾` 只做湿地补给，`腐苔滤肝` 不挂掉落表，`泥潭蓄腐囊` 只做受击/命中恢复。
- 不让任一器官同时承担回血、回蓝、法强、搜刮四条逻辑：每件主体面之外只保留一个主触发。
- 不让腐毒浓度重新变成“只进不出”的日志：花喉、脾囊额外 roll 是固定消费端，九头腐核是持续消费与目标回收端。
- 不跨来源强联动：火法术只用于 Hydra 原生断口封禁，不因为装了沼泽器官就获得火星加成。
- 不把其他生态模板整块换皮：沼泽的浓度、标记、泥脉传染和腐生回收绑定原版湿地方块与 Hydra 实体，不以“换个资源名”的方式从沙漠/地狱复制。
