# 器官设计核心哲学

这个系统本质上是一个 **器官驱动的战斗与成长构筑系统**。玩家装的不是一堆孤立词条，而是在回答四个问题：

- 我来自什么体系？也就是 **来源**。
- 我把这个来源强化成什么玩法？也就是 **流派 / 加成主题**。
- 我主要靠什么方式输出或推进？例如近战、弓箭、法术、资源成长。

设计任何器官时，都要让玩家能看懂这四件事。一个器官可以很简单，但不能只有数值，缺少来源、玩法倾向。

---

## 一、三条主轴

### 1. 来源：器官从哪里来

来源回答的是“这套器官是什么东西改造出来的”。它负责提供身份、视觉、材料来源和基础玩法气质。

来源大致分为三类：

- **原版生态 / 结构扩展**：丛林、沼泽、雪原、海洋、蘑菇岛、幽匿、末影、村庄、掠夺者等。
- **原住民 / 阵营身份**：末影、幽匿、村民、女巫、铁傀儡、掠夺者、不死图腾等身份体系。
- **MOD 来源**：Create、Mekanism、Botania、Tetra、暮色森林、Ice and Fire 等有清晰材料、实体、工艺或结构的体系。

来源不是万能标签。一个来源不需要覆盖近战、弓箭、法术、资源全部方向。不好做、不符合气质的输出方式可以不做。例如 Create 器官不强化法术是正常的，硬做反而会污染机械来源的身份。

需要注意的问题：
- **功能类和加成类器官相配合**： 一个来源中要有具有机制的器官，也要有纯粹加成其他器官的数值器官。如果器官里只有一大堆触发各种特效，技能的器官，但是没有加成，数值不够，就会显得这个来源太复杂，不好用。一般辅助器官数量至少要有4-6个，如果功能器官很多的话可进一步增加
- **只靠文案区分**：如果两套生态器官都是“生命 + 护甲 + 控制 + 回蓝 + 自然法强”，那它们实际玩法就太像。
- **主场过强或离场过弱**：环境触发应该提供适当的额外奖励，而不是让器官离开指定地形就失去基本功能或大幅削弱。

### 2. 加成主题：器官强化什么属性

加成主题回答的是“这个器官把来源往哪个强化方向推”。它可以跨来源复用，用来让不同来源的器官组合到同一套构筑里。

加成主题不能吞掉来源。比如丛林和沼泽可以挂接“铁魔法.自然”，但它们首先仍然是原版生态来源；自然法术只是可选强化方向，不应该让整套生态器官变成 Iron's Spellbooks 的附属插件。

### 3. 流派：玩家实际怎么玩

流派回答的是“玩家装了这些器官后，战斗和成长节奏是什么样”。它不等同于来源，也不等同于某个 MOD。

例如：

- 丛林可以是前排缠斗、持续恢复、自然法坦。
- 沼泽可以是中毒消耗、粘液控场、污染法斗。
- Create 安山可以是蓄压爆发、持续负载、采掘加工。
- Create 黄铜可以是高压增幅、临时上限、稳定产能。

同一个来源可以有多个流派，但每个器官最好只服务一个主要流派，最多带一个次要倾向。不要让一个器官同时承担输出、位移、防御、资源、法术增幅和控场，否则它会变成通用强件，削弱构筑选择。

## 三、联动原则

联动的目标不是让所有东西互相触发，而是让玩家明白“我为什么要把这些器官装在一起”。

### 强联动

强联动应该发生在同一来源、同一流派，或来源不同但主题非常接近的器官之间。需要注意一套联动体系里，不能是一堆具有机制的核心器官而没有辅助增幅器官。给玩家的是众星捧月的感觉，而不是满天月亮。

例如：

- Create 蓄压器官 + Create 放空爆发器官。
- 沼泽粘液器官 + 沼泽中毒器官。
- 丛林承伤器官 + 丛林自然法坦器官。

它的意义是让联动边界清楚、实现简单、玩家容易理解。也可以使用明确的推荐链、条件触发或核心器官驱动，不让联动关系跨来源到处乱跳。

### 弱联动

相近流派之间可以有弱联动，例如条件触发、少量转化、效率提升、额外层数等。

弱联动适合连接：

- 丛林自然恢复 与 沼泽自然污染。
- Create 机械加工 与 Mekanism 工业增产。
- 末影位移 与 黄铜精密节拍。

弱联动不能成为主要强度来源，否则玩家会被迫拼接最强跨系组合，来源身份会被稀释。

### 不建议的联动

不要让距离太远的来源直接形成强联动。例如一个沼泽毒器官不应该因为玩家装了任意机械器官就获得核心倍率；一个 Create 应力器官也不应该无条件强化所有法术。

如果确实需要跨来源联动，应该通过共同主题连接，而不是直接乱连。例如“资源循环器官 4 件后获得加工返还”比“丛林心脏强化黄铜压辊”更清楚。

## 四、资源器官

资源器官不直接负责战斗强度，而是负责 **成长节奏与经济循环**。

它可以做这些事：

- 提高特定材料掉落概率。
- 增加采集、粉碎、筛分、压榨等加工收益。
- 从击杀、挖掘、施法、环境互动中额外获得资源。
- 把某种战斗行为转化为成长收益。

资源器官必须绑定明确行为来源，例如：

- 近战击杀。
- 弓箭命中。
- 法术触发。
- 挖掘 / 采集。
- 环境互动。
- 加工链处理。

不要做纯被动、全局、无条件收益。资源器官如果没有行为门槛，会直接破坏材料进度。

资源器官还需要写清楚限制条件：

- 适用品类是什么。
- 产出倍率或概率上限是什么。
- 是否消耗内部资源、耐久、应力、魔力或能量。
- 是否有冷却、失败副产物、噪音、负面状态或环境要求。

它的目标是让构筑选择影响成长路径。例如近战流更容易获得生物材料，法术流更容易获得魔法材料，机械流更容易稳定产出工业资源，而不是让所有玩家都获得同一套免费收益。

---

## 五、环境触发

环境触发适合生态来源，但必须分层设计。

基础能力应该在普通环境也能使用。主场环境只提供额外强化，例如更高恢复、更低消耗、更强控制、更高资源效率。

推荐分成三层：

- **基础层**：离开主场也可用，保证器官不废。
- **主场层**：在对应群系、天气、方块、水域、生物密度等条件下获得明显收益。
- **构筑层**：多个同源或同主题器官同时存在时，主场收益进一步强化。

要避免玩家用一个简单条件永久绕过平衡。例如只要“潮湿”就给满额强度，很容易被水桶、人工水池或常驻状态滥用。更好的做法是把湿润、群系、方块、行为、冷却和层数结合起来，但不要写成复杂到玩家看不懂的流程。

---

## 六、复杂度边界

器官系统应该让玩家做构筑选择，而不是让玩家背流程图。

可以接受的复杂度：

- 读取当前资源值，例如应力、魔力、能量、毒层。
- 读取简单区间，例如低压、高压、满压、过载。
- 读取最近事件，例如刚受击、刚命中、刚施法、刚挖掘。
- 使用短时间窗口，例如 3 到 8 秒的增幅、冷却或过载。
- 使用少量层数，例如 1 到 5 层。

谨慎使用的复杂度：

- 多阶段工序。
- 多资源互转。
- 长连招判定。
- 可编程序列。
- 大量跨来源条件组合。

特别是 Create / Mekanism 这类机械科技来源，不需要为了体现高级感而做复杂流程控制。T2 比 T1 更高级，可以体现在更高上限、更稳定输出、临时过载窗口、消耗效率、加工收益和更清楚的取舍上，而不是要求玩家或代码维护一套小型自动机。

---

## 七、设计文档必须标注的内容

后续每份来源设计文档，建议每个器官至少写清楚这些字段：

- **来源**：它属于哪个生态、阵营或 MOD。
- **主要流派**：它服务哪种玩法。
- **输出 / 成长方向**：近战、弓箭、法术、资源、生存、机动、控制等。
- **主要效果**：一句话说清楚它实际做什么。
- **触发条件**：常驻、受击、命中、施法、挖掘、环境、主动技能等。
- **联动对象**：和哪些器官强联动，和哪些只是弱联动。
- **限制 / 代价**：冷却、消耗、负面状态、环境限制、倍率上限等。
- **元素点**：如果涉及元素反应或铁魔法倾向，标注 organSynergia 元素点。

一个简单模板：

```text
器官名：
来源：
主要流派：
输出 / 成长方向：
主要效果：
触发条件：
强联动：
弱联动：
限制 / 代价：
Synergia 元素点：
```

不是每个字段都必须写很长，但不要省略来源、流派、方向和限制。缺少这些信息，器官就很容易变成孤立数值件或通用强件。

---

## 八、最终目标

最终目标不是做大量机制堆叠，而是让玩家一眼能理解：

- 我来自什么体系。
- 我是什么玩法风格。
- 我主要靠什么方式输出或成长。
- 我为什么要和这些器官搭配。
- 我为了获得强度付出了什么代价。

只要这五件事清楚，器官可以很简单。反过来，如果这五件事不清楚，即使机制很多，也只是难维护、难平衡、难理解的复杂堆叠。
